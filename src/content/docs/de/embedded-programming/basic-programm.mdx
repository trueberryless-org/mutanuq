Ein typisches C-Programm hat eine `main`-Funktion, welche am Start des Programms aufgerufen wird. Wichtig ist, dass diese Funktion eine Endlosschleife, die sogenannte Arbeitsschleife, enthält, ansonsten würde das Programm aufhören zu laufen. Anders als auf einem PC gibt es auf dem Mikrocontroller nämlich kein Betriebssystem, zu dem das Programm nach dem Ende von `main` zurückkehren könnte.

```c
/*
 * Basic_Program.c
 *
 * Created: 06.09.2069 06:09:00
 * Author : trueberryless
 */

#define F_CPU 16000000

#include <avr/io.h>
#include <avr/interrupt.h>

#define __DELAY_BACKWARD_COMPATIBLE__
#include <util/delay.h>

int main(void)
{
    // einmalige Aktionen

    while (1)
    {
        // Arbeitsschleife - mehrmalige Aktionen
    }
}
```

## Erklärung

| Zeile                                 | Bedeutung                                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `#define F_CPU 16000000`              | Teilt den Bibliotheken mit, dass der Mikrocontroller mit 16 MHz getaktet ist. Wird vor allem von `_delay_ms()` benötigt, um die Wartezeit richtig zu berechnen. |
| `#include <avr/io.h>`                 | Enthält die Namen aller Register (z. B. `PORTB`, `DDRB`) und Bits des verwendeten Mikrocontrollers.                                        |
| `#include <avr/interrupt.h>`          | Wird für [Interrupts](/de/embedded-programming/interrupts/) benötigt (`sei()`, `cli()`, `ISR()`).                                          |
| `#define __DELAY_BACKWARD_COMPATIBLE__` | Erlaubt es, `_delay_ms()` auch mit Variablen statt nur mit konstanten Zahlen aufzurufen.                                                 |
| `#include <util/delay.h>`             | Stellt die Warte-Funktionen `_delay_ms()` und `_delay_us()` bereit.                                                                        |

Vor der Arbeitsschleife werden typischerweise alle Konfigurationen vorgenommen, zum Beispiel welche Pins [Ein- oder Ausgänge](/de/embedded-programming/special-function-register/) sind oder wie ein [Timer](/de/embedded-programming/timer/) arbeiten soll. In der Arbeitsschleife läuft dann die eigentliche Logik des Programms.
