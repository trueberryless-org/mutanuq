Pointer sind Variablen, welche Speicheradressen aufnehmen und somit zu anderen Daten zeigen. Pointer bieten ein umfangreiches und mächtiges Tool, um mit Datentypen zu interagieren, welche mehr als ein Byte Speicherplatz benötigen. Vor allem für den Umgang mit Arrays sind Pointer in `C` überaus wichtig.

Wie man im nachfolgenden Code sehen kann, gibt es die beiden Operatoren `*` und `&` in Bezug auf Pointer.

```c
// Variable i mit Wert 12
int i = 12;

// Pointer-Variable p
int *p = NULL;

// Pointer auf i
p = &i;

// Ausgabe von p (Adresse)
printf("Adresse: %p", p); // zB: Adresse: 0x00000008

// Ausgabe des Wertes, auf den p zeigt
printf("Wert: %d", *p); // Wert: 12
```

Der finale Zustand des Programms im Arbeitsspeicher (Stack) ist hier visualisiert (die Adressen sind natürlich frei erfunden und dies ist nur ein fiktiver Auszug aus dem Arbeitsspeicher):

| Variablenname | Adresse    | Wert       |
| ------------- | ---------- | ---------- |
| `i`           | `00000008` | 12         |
| `p`           | `00000069` | `00000008` |

## Mit Arrays arbeiten

Häufig müssen wir mit Arrays, sprich Listen von Werten, arbeiten. Ein Array ist ein zusammenhängender Speicherbereich, in dem alle Elemente direkt hintereinander liegen. Ein Array ist selbst kein Pointer, wird aber in fast allen Ausdrücken automatisch in einen Pointer auf sein erstes Element umgewandelt (_Array-to-Pointer Decay_). Da es in `C` keine Referenzen gibt, wird auch beim Übergeben eines Arrays an eine Funktion nur dieser Pointer übergeben. Aus diesem Grund ist es nicht möglich, innerhalb der aufgerufenen Funktion die Größe des Arrays herauszufinden. Man muss sie als zusätzlichen Parameter mitgeben. Somit zeigen die Pointer in diesen Code-Beispielen auf dieselbe Adresse:

```c del="&"
uint8_t numbers[] = { 1, 2, 3, 4, 5 };
uint8_t *p = &numbers;
```

```c
uint8_t numbers[] = { 1, 2, 3, 4, 5 };
uint8_t *p = numbers; // Automatische Umwandlung in einen Pointer auf numbers[0]
```

Beide Pointer in dem obigen Beispiel zeigen somit auf das **erste Element** des Arrays. Die erste Variante mit `&` liefert allerdings genau genommen einen Pointer auf das gesamte Array (Typ `uint8_t (*)[5]`), weshalb der Compiler eine Warnung ausgibt. Richtig ist die zweite Variante. Ein Teil des Arbeitsspeichers (Stack) sieht folgendermaßen aus (Adressen frei erfunden):

| Variablenname | Adresse    | Wert       |
| ------------- | ---------- | ---------- |
| `numbers[0]`  | `00000F00` | 1          |
| `numbers[1]`  | `00000F01` | 2          |
| `numbers[2]`  | `00000F02` | 3          |
| `numbers[3]`  | `00000F03` | 4          |
| `numbers[4]`  | `00000F04` | 5          |
| `p`           | `00000F42` | `00000F00` |

Für das Array selbst wird also keine zusätzliche Adresse gespeichert. Der Name `numbers` steht direkt für den Speicherbereich ab `00000F00`.

Nun kann man auf die einzelnen Werte des Arrays zugreifen, indem man entweder den `[]`-Operator nutzt oder den Index und den Pointer addiert und anschließend dereferenziert. Bei der Addition wird der Index automatisch mit der Größe des Datentyps multipliziert (_Zeigerarithmetik_): Bei einem `uint16_t`-Array würde `numbers + 2` also 4 Bytes weiter zeigen.

```c
// []-Operator
uint8_t three = numbers[2];

// Pointer Zugriff
three = *(numbers + 2);
```

Wenn man alle Elemente dieses Arrays nun ausgeben will, kann der `C-Code` von unten verwendet werden. Der Operator `sizeof` liefert hier die Größe des gesamten Arrays in Bytes. Das funktioniert nur in diesem Scope, da hier auch die Variable `numbers` deklariert ist. In einer Funktion, der das Array übergeben wurde, würde `sizeof` nur die Größe des Pointers liefern. Da `uint8_t` genau ein Byte groß ist, entspricht die Größe hier der Anzahl der Elemente. Allgemein berechnet man die Anzahl mit `sizeof(numbers) / sizeof(numbers[0])`.

```c
uint8_t numbers[5] = { 1, 2, 3, 4, 5 };

for(int i = 0; i < sizeof(numbers); i++) {
    printf("%u", *(numbers + i));
}
```

Bei Strings, sprich Arrays von Zeichen, wird beim Erstellen automatisch ein Terminierungssymbol (`\0`) nach dem letzten Zeichen gespeichert, sodass man die folgende `while`-Schleife zum Ausgeben verwenden kann. Das Array muss deshalb immer mindestens ein Zeichen größer sein als der eigentliche Text. Die `while`-Schleife hört automatisch am Ende der Zeichenkette auf, da das Terminierungszeichen `\0` einer falschen Bedingung entspricht. Genau auf diese Art und Weise werden beim [USART](/de/embedded-programming/usart#daten-senden) die Zeichen einzeln hintereinander versendet.

```c
char buffer[10] = "Hallo";
char *p = buffer;

while(*p) {
    printf("%c", *p);
    p++;
}
```

Wohlgemerkt kann man das Dereferenzieren und Addieren des Pointers gleich in einer Zeile schreiben.

```c "*p++"
char buffer[10] = "Hallo";
char *p = buffer;

while(*p) {
    printf("%c", *p++);
}
```
