Ein Essay (_essay_) ist ein strukturierter, argumentierender Text zu einer Frage oder Behauptung. Er richtet sich an eine allgemeine, gebildete Leserschaft, etwa deine Lehrkraft oder die Leser einer Schulzeitung, und soll mit nachvollziehbaren Argumenten und Beispielen überzeugen. Im Unterschied zum [Artikel](/de/languages/text_types/article/) steht nicht die Unterhaltung im Vordergrund, sondern eine klare, logisch aufgebaute Argumentation.

Man unterscheidet zwei Formen:

| Form                                           | Ziel                                                                 | Wo steht die eigene Meinung?               |
| ---------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------ |
| **Opinion Essay** (_argumentative essay_)      | eine Position vertreten und den Leser davon überzeugen               | in der Einleitung und im ganzen Text       |
| **For-and-against Essay** (_discursive essay_) | Pro- und Kontra-Argumente ausgewogen gegenüberstellen                | erst im Schluss                            |

:::note
Der Essay ist eine fixe Textsorte der SRDP Englisch an der AHS. An der BHS kommt er in der Matura in der Regel nicht vor, wird aber im Unterricht geübt, weil seine Argumentationsstruktur in Artikel, Blogbeitrag, Leserbrief und Bericht wieder vorkommt.
:::

## Merkmale

-   formell bis neutral, keine Umgangssprache und keine Kurzformen (`do not` statt `don't`)
-   klarer Titel, meist die Frage oder das Thema der Aufgabe
-   jeder Absatz behandelt **ein** Argument und beginnt mit einem **Topic Sentence**
-   Argumente werden mit Beispielen, Fakten oder Erfahrungen gestützt
-   **Linking Words** verbinden Sätze und Absätze logisch
-   kein direktes Ansprechen des Lesers mit `you`; verallgemeinernd schreibt man `people`, `many students` oder `one`
-   im Opinion Essay `I` nur in Einleitung und Schluss, im Hauptteil eher unpersönliche Formulierungen

## Aufbau

### Titel

Der Titel nennt das Thema knapp. Häufig übernimmt man die Frage aus der Aufgabenstellung.

> Should smartphones be banned in schools?

### Einleitung

Die Einleitung weckt Interesse (_hook_), etwa mit einer Zahl, einer Frage oder einer kurzen Situation, führt zum Thema hin und endet mit der **These** (_thesis statement_). Im Opinion Essay ist das deine Meinung, im For-and-against Essay kündigst du an, dass beide Seiten betrachtet werden.

> Nearly every teenager in Austria owns a smartphone, and many of them check it dozens of times a day. While some argue that phones distract pupils, I am convinced that a complete ban would do more harm than good.

### Hauptteil

Der Hauptteil besteht meist aus zwei bis drei Absätzen. Jeder Absatz folgt dem Muster **Topic Sentence, Begründung, Beispiel**.

-   **Opinion Essay:** zwei Absätze mit Argumenten für deine Position, danach ein Absatz mit einem Gegenargument, das du widerlegst (_counter-argument and refutation_).
-   **For-and-against Essay:** ein Absatz mit Argumenten dafür, ein Absatz mit Argumenten dagegen, beide gleich ausführlich.

> To begin with, smartphones are useful learning tools. Pupils can look up unknown words, check facts or use learning apps during lessons. In our IT classes, for example, we regularly use our phones to test responsive websites.

:::caution
Ein Absatz, ein Argument. Wenn du zwei Argumente in einen Absatz packst, wird die Gliederung unklar und du verlierst Punkte beim Kriterium _Organisation and Layout_.
:::

### Schluss

Der Schluss fasst die wichtigsten Argumente kurz zusammen, ohne neue Argumente einzuführen, und formuliert die eigene Meinung (im For-and-against Essay zum ersten Mal). Ein Ausblick oder eine Empfehlung rundet den Text ab.

> All things considered, the advantages of smartphones clearly outweigh the risks. Instead of banning them, schools should set clear rules for when phones may be used.

## Phrasen

| Einleitung                                                |
| --------------------------------------------------------- |
| These days, ... has become a hotly debated issue.         |
| It is often claimed that ...                              |
| Many people believe that ..., while others argue that ... |
| This essay will discuss whether ...                       |
| In my opinion, ... because ...                            |

| Argumente einleiten und ergänzen            |
| ------------------------------------------- |
| To begin with, ... / First of all, ...      |
| Furthermore, ... / Moreover, ...            |
| In addition to this, ...                    |
| Another argument in favour of ... is that ... |
| Not only ... but also ...                   |

| Beispiele und Begründungen                 |
| ------------------------------------------ |
| For example, ... / For instance, ...       |
| A good example of this is ...              |
| This is because ... / This is due to ...   |
| As a result, ... / Consequently, ...       |
| Studies have shown that ...                |

| Gegenargumente und Widerlegung                       |
| ---------------------------------------------------- |
| On the other hand, ...                               |
| Opponents of ... argue that ...                      |
| Admittedly, ... However, ...                         |
| Although it is true that ..., ...                    |
| This argument does not hold, because ...             |

| Schluss                                       |
| --------------------------------------------- |
| In conclusion, ... / To sum up, ...           |
| All things considered, ...                    |
| On balance, I believe that ...                |
| Taking everything into account, ...           |
| It is therefore advisable to ...              |

Weitere Linking Words und ihre Zeichensetzung findest du unter [Satzbau](/de/languages/english/sentence_structure/#linking-words-und-konnektoren).
