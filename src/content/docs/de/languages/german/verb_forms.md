Ein finites Verb zeigt nicht nur Person und Numerus, sondern auch die **Zeit** (Tempus), die **Handlungsrichtung** (Aktiv oder Passiv) und die **Aussageweise** (Modus). Für die Matura sind vor allem die Tempora beim Zusammenfassen und Analysieren sowie der Konjunktiv I in der indirekten Rede wichtig: Wer Aussagen aus einem Ausgangstext wiedergibt, muss sie korrekt als fremde Aussagen kennzeichnen.

## Tempora

Das Deutsche hat sechs Zeitformen. Präsens und Präteritum sind **einfache** Formen, die anderen werden mit Hilfsverben **zusammengesetzt**.

| Tempus                     | Bildung                                  | Beispiel (Aktiv)                      |
| -------------------------- | ---------------------------------------- | ------------------------------------- |
| Präsens                    | Stamm + Personalendung                   | Sie programmiert. Er fährt.           |
| Präteritum (Imperfekt)     | schwach: Stamm + -te; stark: Ablaut      | Sie programmierte. Er fuhr.           |
| Perfekt                    | haben/sein (Präsens) + Partizip II       | Sie hat programmiert. Er ist gefahren. |
| Plusquamperfekt            | haben/sein (Präteritum) + Partizip II    | Sie hatte programmiert. Er war gefahren. |
| Futur I                    | werden (Präsens) + Infinitiv             | Sie wird programmieren.               |
| Futur II                   | werden (Präsens) + Partizip II + haben/sein | Sie wird programmiert haben. Er wird gefahren sein. |

### Verwendung

-   **Präsens:** Gegenwart (Ich schreibe gerade.), allgemeingültige Aussagen (Wasser siedet bei 100 °C.), Zukunft mit Zeitangabe (Morgen fahre ich nach Graz.) und historisches Präsens zur Vergegenwärtigung (1955 unterzeichnet Österreich den Staatsvertrag.). Zusammenfassungen, Analysen und Interpretationen schreibst du im Präsens.
-   **Präteritum:** abgeschlossene Vergangenheit, vor allem in geschriebenen Erzählungen und Berichten. Bei `sein`, `haben` und den Modalverben ist es auch mündlich üblich (Ich war krank. Ich musste gehen.).
-   **Perfekt:** Vergangenes mit Bezug zur Gegenwart, und die übliche Vergangenheitsform im Gesprochenen. In Österreich und Süddeutschland wird mündlich fast nur das Perfekt verwendet. In Textsorten wie der Zusammenfassung drückt das Perfekt Vorzeitigkeit zum Präsens aus.
-   **Plusquamperfekt:** Vorvergangenheit, also etwas, das vor einem anderen vergangenen Geschehen abgeschlossen war: Nachdem sie das Update **installiert hatte**, startete sie den Rechner neu.
-   **Futur I:** Zukunft (oft durch Präsens ersetzt) oder Vermutung über die Gegenwart: Er **wird** wohl noch im Büro **sein**.
-   **Futur II:** in der Zukunft abgeschlossen (Bis Freitag **werde** ich das Projekt **beendet haben**.) oder Vermutung über Vergangenes (Sie **wird** den Bus **verpasst haben**.).

### Zeitenfolge

Achte auf eine einheitliche Zeitstufe. Wechselst du in einem Text ohne Grund zwischen Präsens und Präteritum, ist das ein Fehler. Vorzeitigkeit drückst du so aus:

| Haupthandlung in | Vorzeitige Handlung in |
| ---------------- | ---------------------- |
| Präsens          | Perfekt                |
| Präteritum       | Plusquamperfekt        |

## Aktiv und Passiv

Im **Aktiv** steht der Handelnde (Agens) im Mittelpunkt, im **Passiv** die Handlung oder der Betroffene. Das Akkusativobjekt des Aktivsatzes wird zum Subjekt des Passivsatzes, der Handelnde kann mit `von` oder `durch` genannt werden oder ganz wegfallen.

> Aktiv: Die Technikerin **installiert** den Server.
> Passiv: Der Server **wird** (von der Technikerin) **installiert**.

### Vorgangspassiv

Das **Vorgangspassiv** (werden-Passiv) beschreibt einen Vorgang: werden + Partizip II.

| Tempus          | Vorgangspassiv                              |
| --------------- | ------------------------------------------- |
| Präsens         | Der Server wird installiert.                |
| Präteritum      | Der Server wurde installiert.               |
| Perfekt         | Der Server ist installiert worden.          |
| Plusquamperfekt | Der Server war installiert worden.          |
| Futur I         | Der Server wird installiert werden.         |
| Futur II        | Der Server wird installiert worden sein.    |

Im Perfekt heißt es im Passiv `worden`, nicht `geworden`: Der Server ist installiert **worden**. `geworden` steht nur beim Vollverb werden (Sie ist Ärztin geworden.).

Auch Verben ohne Akkusativobjekt können ein subjektloses (unpersönliches) Passiv bilden: Hier **wird** nicht **geraucht**. Am Wochenende **wird gearbeitet**.

### Zustandspassiv

Das **Zustandspassiv** (sein-Passiv) beschreibt das Ergebnis eines Vorgangs: sein + Partizip II.

> Vorgang: Das Geschäft **wird** um 18 Uhr **geschlossen**.
> Zustand: Das Geschäft **ist** **geschlossen**.

### Passiv und Stil

Das Passiv ist sinnvoll, wenn der Handelnde unwichtig, unbekannt oder selbstverständlich ist, etwa in Anleitungen, Protokollen und technischen Texten (Die Daten werden verschlüsselt übertragen.). In argumentativen Texten wirkt zu viel Passiv unpersönlich und verschleiert die Verantwortung. Mehr dazu unter [Stil](/de/languages/german/style/).

Ersatzformen für das Passiv sind `man` (Man installiert den Server.), `sich lassen` (Das Problem lässt sich lösen.), `sein + zu + Infinitiv` (Die Aufgabe ist bis Freitag zu erledigen.) und Adjektive auf `-bar` (Das Problem ist lösbar.).

## Modi

Der Modus zeigt, wie der Sprecher eine Aussage einschätzt.

| Modus        | Funktion                                           | Beispiel                              |
| ------------ | -------------------------------------------------- | ------------------------------------- |
| Indikativ    | Wirklichkeitsform: Tatsachen                       | Sie kommt morgen.                     |
| Konjunktiv I | Möglichkeitsform: indirekte Rede, Wunsch, Anweisung | Sie sagt, sie komme morgen.         |
| Konjunktiv II | irreale Aussagen, Wünsche, Höflichkeit, Ersatzform | Wenn sie Zeit hätte, käme sie.      |
| Imperativ    | Befehlsform: Aufforderungen                        | Komm morgen!                          |

### Konjunktiv I

Der Konjunktiv I wird vom **Präsensstamm** (Infinitiv ohne -en) gebildet, mit den Endungen -e, -est, -e, -en, -et, -en.

| Person      | kommen    | haben     | können    | sein          |
| ----------- | --------- | --------- | --------- | ------------- |
| ich         | komme     | habe      | könne     | sei           |
| du          | kommest   | habest    | könnest   | sei(e)st      |
| er/sie/es   | komme     | habe      | könne     | sei           |
| wir         | kommen    | haben     | können    | seien         |
| ihr         | kommet    | habet     | könnet    | seiet         |
| sie/Sie     | kommen    | haben     | können    | seien         |

Man sieht sofort: Viele Formen sind mit dem Indikativ Präsens identisch (ich komme, wir kommen, sie kommen). Eindeutig ist der Konjunktiv I vor allem in der **3. Person Singular** (er komme, sie habe, es könne) und beim Verb `sein` in allen Personen.

Weitere Verwendungen: Wunsch oder Aufforderung in festen Wendungen (Es **lebe** die Freiheit! Man **nehme** 200 g Mehl.).

### Konjunktiv II

Der Konjunktiv II wird vom **Präteritumstamm** gebildet. Starke Verben bekommen dabei meist einen Umlaut, die Endungen sind -e, -est, -e, -en, -et, -en.

| Infinitiv | Präteritum | Konjunktiv II |
| --------- | ---------- | ------------- |
| sein      | war        | wäre          |
| haben     | hatte      | hätte         |
| werden    | wurde      | würde         |
| kommen    | kam        | käme          |
| gehen     | ging       | ginge         |
| wissen    | wusste     | wüsste        |
| können    | konnte     | könnte        |
| machen    | machte     | machte (gleich wie Präteritum) |

Bei **schwachen Verben** ist der Konjunktiv II formgleich mit dem Präteritum (ich machte). Deshalb ersetzt man ihn meist durch die würde-Form.

Verwendung:

-   **irreale Bedingung:** Wenn ich mehr Zeit **hätte**, **würde** ich Rust lernen.
-   **irrealer Wunsch:** **Wären** doch schon Ferien!
-   **Höflichkeit:** **Könnten** Sie mir bitte helfen? Ich **hätte** gern einen Kaffee.
-   **Ersatzform** des Konjunktivs I in der indirekten Rede (siehe unten).

Die Vergangenheit des Konjunktivs II bildest du mit `hätte` oder `wäre` + Partizip II: Wenn ich das gewusst **hätte**, **wäre** ich früher **gekommen**.

### würde-Form

Die **würde-Form** (würde + Infinitiv) ist eine umschreibende Form des Konjunktivs II. Sie ist in folgenden Fällen sinnvoll:

-   wenn der Konjunktiv II mit dem Präteritum übereinstimmt (bei schwachen Verben): `sie arbeiteten` wird zu `sie würden arbeiten`.
-   wenn der Konjunktiv II veraltet oder ungewöhnlich klingt: `hülfe`, `stürbe`, `begönne` wird zu `würde helfen`, `würde sterben`, `würde beginnen`.

Bei `sein`, `haben`, `werden`, den Modalverben und häufigen starken Verben (`käme`, `ginge`, `wüsste`, `gäbe`) verwendest du in geschriebenen Texten besser die einfache Form. Doppelte würde-Formen in einem Satz (`*Wenn ich Zeit haben würde, würde ich kommen`) gelten als schlechter Stil.

### Imperativ

Der Imperativ richtet sich direkt an eine oder mehrere Personen.

| Form            | Bildung                     | Beispiele                         |
| --------------- | --------------------------- | --------------------------------- |
| 2. Person Sg.   | Stamm (+ -e)                | Komm! Warte! Arbeite!             |
| 2. Person Pl.   | wie Indikativ               | Kommt! Wartet!                    |
| Höflichkeitsform | Infinitiv + Sie            | Kommen Sie! Warten Sie!           |

Verben mit dem Wechsel e zu i/ie im Präsens behalten ihn im Imperativ Singular und bekommen kein -e: nehmen, **nimm**!; lesen, **lies**!; geben, **gib**!; helfen, **hilf**! Verben mit a zu ä haben keinen Umlaut: fahren, **fahr**! Der Imperativ von `sein` lautet **sei**! und **seid**!

## Indirekte Rede

In der **indirekten Rede** gibst du wieder, was eine andere Person gesagt oder geschrieben hat, ohne es wörtlich zu zitieren. Der Konjunktiv zeigt dabei an, dass es sich um eine fremde Aussage handelt, für deren Wahrheit du nicht bürgst. Das ist für Zusammenfassung, Textanalyse und Leserbrief bei der SRDP wichtig: Konjunktiv-Fehler gelten als Sprachrichtigkeitsfehler.

### Umwandlung

Beim Umwandeln von direkter in indirekte Rede ändern sich:

1.  **Modus:** Indikativ wird Konjunktiv I (oder Ersatzform).
2.  **Pronomen** und Possessivpronomen: aus Sicht des Berichtenden.
3.  **Orts- und Zeitangaben**, wenn nötig: `hier` wird `dort`, `heute` wird `an diesem Tag`, `morgen` wird `am nächsten Tag`.
4.  Ein **redeeinleitendes Verb** oder eine Wendung kennzeichnet die Wiedergabe: sagen, behaupten, betonen, fordern, kritisieren, laut, nach Ansicht von.

> Direkt: Die Autorin schreibt: „Ich halte das Handyverbot an Schulen für sinnvoll.“
> Indirekt: Die Autorin schreibt, sie **halte** das Handyverbot an Schulen für sinnvoll.

`dass` kann die indirekte Rede einleiten, dann steht das Verb am Ende: Sie schreibt, dass sie das Verbot für sinnvoll **halte**.

### Zeitstufen

Der Konjunktiv kennt keine sechs Tempora, sondern nur drei **Zeitstufen**. Die Zeitstufe richtet sich nach der direkten Rede, nicht nach dem Tempus des einleitenden Verbs.

| Zeitstufe in der direkten Rede  | Konjunktiv I                      | Beispiel                                                   |
| ------------------------------- | --------------------------------- | ---------------------------------------------------------- |
| Gegenwart (Präsens)             | Konjunktiv I Präsens              | Er sagt/sagte, er **arbeite** an einem Projekt.            |
| Vergangenheit (Präteritum, Perfekt, Plusquamperfekt) | Konjunktiv I Perfekt (habe/sei + Partizip II) | Er sagt/sagte, er **habe** an einem Projekt **gearbeitet**. Sie sagt, sie **sei** gestern **gekommen**. |
| Zukunft (Futur I)               | Konjunktiv I Futur (werde + Infinitiv) | Er sagt/sagte, er **werde** an einem Projekt **arbeiten**. |

### Ersatzregeln

Weil viele Formen des Konjunktivs I mit dem Indikativ übereinstimmen, gibt es feste **Ersatzregeln**:

1.  **Konjunktiv I**, wenn er sich vom Indikativ unterscheidet: er **habe**, sie **komme**, es **sei**.
2.  Ist der Konjunktiv I **gleich dem Indikativ**, nimmst du den **Konjunktiv II**: sie haben (Ind. = Konj. I) wird zu sie **hätten**.
3.  Ist auch der Konjunktiv II **gleich dem Präteritum Indikativ** (schwache Verben) oder klingt er veraltet, nimmst du die **würde-Form**: sie arbeiten (Ind. = Konj. I), sie arbeiteten (Konj. II = Präteritum), also sie **würden arbeiten**.

| Direkte Rede                       | Konj. I        | eindeutig? | Ersatz            | Indirekte Rede                          |
| ---------------------------------- | -------------- | ---------- | ----------------- | --------------------------------------- |
| „Ich habe keine Zeit.“ (er)        | er habe        | ja         |                   | Er sagt, er habe keine Zeit.            |
| „Wir haben keine Zeit.“ (sie, Pl.) | sie haben      | nein       | sie hätten        | Sie sagen, sie hätten keine Zeit.       |
| „Wir kommen morgen.“ (sie, Pl.)    | sie kommen     | nein       | sie kämen         | Sie sagen, sie kämen morgen.            |
| „Wir arbeiten viel.“ (sie, Pl.)    | sie arbeiten   | nein       | sie arbeiteten = Präteritum, also würde-Form | Sie sagen, sie würden viel arbeiten. |
| „Ich bin müde.“ (sie, Sg.)         | sie sei        | ja         |                   | Sie sagt, sie sei müde.                 |
| „Wir haben gewonnen.“ (sie, Pl.)   | sie haben gewonnen | nein   | sie hätten gewonnen | Sie sagen, sie hätten gewonnen.       |

:::tip[Merke]
Für die 3. Person Singular reicht fast immer der Konjunktiv I (er habe, sie werde, es gebe). Probleme entstehen vor allem im Plural und in der 1. Person. Nimm den Konjunktiv II nie, wenn der Konjunktiv I eindeutig ist: `*Der Autor meint, das Handy wäre schädlich` ist in einer Textanalyse ungenau, richtig ist `sei`.
:::

### Fragen und Aufforderungen

-   **Entscheidungsfragen** werden mit `ob` eingeleitet: „Kommst du mit?“ wird zu Sie fragt, **ob** er mitkomme.
-   **Ergänzungsfragen** behalten das Fragewort: „Wann beginnt der Kurs?“ wird zu Er fragt, **wann** der Kurs beginne.
-   **Aufforderungen** werden mit `sollen` (Befehl) oder `mögen` (Bitte) wiedergegeben: „Schließ die Tür!“ wird zu Sie sagt, er **solle** die Tür schließen. „Bitte hilf mir!“ wird zu Er bittet, sie **möge** ihm helfen.

### Berichtende Wendungen

Damit sich eine Wiedergabe nicht ständig mit „sagt“ wiederholt, verwende abwechslungsreiche redeeinleitende Verben. Achte darauf, dass sie die Haltung des Autors richtig treffen.

| neutral           | zustimmend / betonend | kritisch / ablehnend | fordernd    |
| ----------------- | --------------------- | -------------------- | ----------- |
| erklären, berichten, darlegen, ausführen | betonen, hervorheben, unterstreichen | kritisieren, bemängeln, bezweifeln, einwenden | fordern, verlangen, appellieren, empfehlen |

Daneben gibt es nicht-verbale Kennzeichnungen mit Konjunktiv oder Indikativ: **laut** der Autorin, **nach Ansicht** des Autors, **wie** die Studie **zeigt**.
