Für ein Pflichtpraktikum im Ausland, ein Studium oder eine Stelle in einem internationalen Unternehmen brauchst du englische Bewerbungsunterlagen: einen **Lebenslauf** (_CV_ oder _résumé_) und ein **Bewerbungsschreiben** (_cover letter_). Englischsprachige Unterlagen folgen anderen Konventionen als österreichische. Ein übersetzter österreichischer Lebenslauf mit Foto, Geburtsdatum und Unterschrift wirkt in Großbritannien oder den USA ungewohnt.

## Lebenslauf

### Begriffe

| Begriff         | Bedeutung                                                                         |
| --------------- | --------------------------------------------------------------------------------- |
| **CV** (_curriculum vitae_) | in Großbritannien, Irland und Europa: der übliche Lebenslauf          |
| **résumé** (auch _resume_) | in den USA und Kanada: kurzer Lebenslauf für Bewerbungen; ein _CV_ ist dort ein ausführlicher akademischer Lebenslauf |
| **Europass CV** | einheitliches europäisches Format der Europäischen Union                          |

### Britische und amerikanische Konventionen

| Merkmal                         | Österreich (üblich)    | Großbritannien (CV)            | USA (résumé)                  |
| ------------------------------- | ---------------------- | ------------------------------ | ----------------------------- |
| Länge                           | 1 bis 2 Seiten         | meist 2 Seiten                 | meist 1 Seite                 |
| Foto                            | häufig                 | nein                           | nein                          |
| Geburtsdatum, Familienstand     | häufig                 | nein                           | nein                          |
| Reihenfolge                     | meist umgekehrt chronologisch | umgekehrt chronologisch | umgekehrt chronologisch     |
| Profil am Anfang                | selten                 | _personal statement_ üblich    | _summary_ üblich              |
| Unterschrift                    | häufig                 | nein                           | nein                          |

Dass Foto, Alter und Familienstand fehlen, hat mit dem Schutz vor Diskriminierung zu tun: Arbeitgeber sollen nur nach Qualifikation entscheiden, und viele lehnen Unterlagen mit solchen Angaben sogar ab, um sich nicht angreifbar zu machen.

### Aufbau

**Umgekehrt chronologisch** (_reverse chronological order_) heißt: Das Neueste steht oben.

1.  **Personal details:** Name (als Überschrift, nicht „CV“), Telefonnummer mit Ländervorwahl (`+43 ...`), E-Mail-Adresse, Wohnort, Links zu LinkedIn oder GitHub
2.  **Personal statement / Profile:** drei bis vier Sätze: wer du bist, was du kannst, was du suchst
3.  **Education:** Schule, Fachrichtung, Zeitraum, Schwerpunkte, Diplomarbeit
4.  **Work experience:** Praktika, Ferialjobs, Projekte; jeweils Firma, Ort, Zeitraum, Position und Aufgaben als Aufzählung mit Tätigkeitsverben
5.  **Skills:** technische Kenntnisse (Programmiersprachen, Tools, Betriebssysteme), Sprachen mit GER-Niveau (`German: native`, `English: C1`), Soft Skills mit Beleg
6.  **Certificates / Awards:** etwa Cisco CCNA, ECDL/ICDL, Wettbewerbe
7.  **Interests** (optional): nur, wenn sie etwas über dich aussagen
8.  **References:** heute meist weggelassen oder `References available on request`

### HTL-Abschluss auf Englisch

| Deutsch                                         | Englisch                                                                  |
| ----------------------------------------------- | ------------------------------------------------------------------------- |
| Höhere Technische Lehranstalt (HTL)             | Higher Technical College (HTL)                                            |
| Abteilung Informationstechnologie               | Department of Information Technology                                      |
| Reife- und Diplomprüfung                        | Matura and Diploma Examination (Austrian higher education entrance qualification) |
| Diplomarbeit                                    | diploma thesis                                                            |
| Pflichtpraktikum                                | compulsory work placement, internship                                     |
| Ausbildungsschwerpunkt                          | specialisation                                                            |

Schulnoten übersetzt man nicht wörtlich. Wenn du sie angibst, erkläre die österreichische Notenskala (1 = best, 5 = fail) oder schreib `passed with distinction` (mit ausgezeichnetem Erfolg) bzw. `passed with merit` (mit gutem Erfolg). Für die Matura-Zeugnisse der HTL gibt es eine offizielle englische Zeugniserläuterung (_Europass Certificate Supplement_).

### Tätigkeitsverben

Beschreibe Aufgaben mit **Action Verbs** im Past Simple (für frühere Tätigkeiten) und möglichst mit messbarem Ergebnis:

| Verben                                          | Beispiel                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------- |
| `developed`, `designed`, `implemented`, `built` | `Developed a web app for booking school rooms (React, ASP.NET).`       |
| `configured`, `installed`, `maintained`, `set up` | `Configured VLANs and firewall rules for a network with 120 clients.` |
| `automated`, `improved`, `reduced`, `optimised` | `Automated backups with PowerShell, saving 2 hours per week.`          |
| `led`, `organised`, `coordinated`, `presented`  | `Led a team of four in our diploma project.`                           |
| `tested`, `analysed`, `documented`              | `Wrote unit tests and documentation for the API.`                      |

### Europass

Der **Europass** ist eine Initiative der Europäischen Union, die Qualifikationen in Europa vergleichbar machen soll. Auf dem Europass-Portal kannst du kostenlos einen Lebenslauf online erstellen und als PDF herunterladen, in allen EU-Sprachen. Sprachkenntnisse werden darin nach dem **Gemeinsamen Europäischen Referenzrahmen** (GER, englisch CEFR) von A1 bis C2 selbst eingestuft, getrennt nach Verstehen, Sprechen und Schreiben. Ein Foto ist im Europass optional. Viele Arbeitgeber in Großbritannien und den USA bevorzugen allerdings einen frei gestalteten CV oder ein Résumé.

## Cover Letter

Das Bewerbungsschreiben (_cover letter_, in der E-Mail auch der E-Mail-Text selbst) ergänzt den Lebenslauf. Es wiederholt ihn nicht, sondern zeigt, **warum du zu genau dieser Stelle passt**. Es ist höchstens eine Seite lang. Inhaltliche Regeln und Phrasen findest du auch unter [Bewerbungs-E-Mail](/de/languages/text_types/email/#bewerbungs-e-mail), das Layout unter [Brief](/de/languages/text_types/letter/#aufbau).

### Aufbau

| Absatz                     | Inhalt                                                                          |
| -------------------------- | ------------------------------------------------------------------------------- |
| Anrede                     | `Dear Ms Smith,` (Namen recherchieren), sonst `Dear Hiring Manager,`            |
| Einleitung                 | Stelle, wo du davon erfahren hast, ein Satz, warum du dich bewirbst             |
| Hauptteil 1: Was du kannst | zwei bis drei Qualifikationen aus der Stellenausschreibung mit konkretem Beleg  |
| Hauptteil 2: Warum diese Firma | was dich an der Firma interessiert, was du beitragen kannst                 |
| Schluss                    | Verfügbarkeit, Bitte um ein Gespräch, Dank                                      |
| Grußformel                 | `Yours sincerely,` (Name bekannt) oder `Yours faithfully,` (Name unbekannt), Name |

### Phrasen

| Einleitung                                                                                  |
| ------------------------------------------------------------------------------------------- |
| I am writing to apply for the position of junior developer advertised on your website.      |
| I would like to apply for a four-week summer internship in your IT department.              |
| Ms Huber, your Head of IT, suggested that I contact you about ...                           |

| Qualifikationen                                                                             |
| ------------------------------------------------------------------------------------------- |
| I am currently in my final year at a Higher Technical College, specialising in ...          |
| During my internship at ..., I gained hands-on experience in ...                            |
| In our diploma project, I was responsible for ...                                           |
| I have a solid knowledge of ... and am familiar with ...                                    |
| I am particularly interested in this position because ...                                   |

| Schluss                                                                                     |
| ------------------------------------------------------------------------------------------- |
| I am available from July to September.                                                      |
| I would welcome the opportunity to discuss my application in an interview.                  |
| Thank you for considering my application. I look forward to hearing from you.               |

:::caution
Schreib jeden Cover Letter neu für die konkrete Stelle. Ein allgemeiner Text, der zu jeder Firma passt, fällt sofort auf. Lass ihn Korrektur lesen: Rechtschreibfehler sind in Bewerbungen ein häufiger Ausschlussgrund.
:::

## Vorstellungsgespräch

### Vorbereitung

-   Informiere dich über die Firma (Produkte, Kunden, Werte).
-   Lies die Stellenausschreibung genau und überlege dir zu jeder Anforderung ein Beispiel.
-   Übe die Antworten auf typische Fragen laut auf Englisch.
-   Bereite zwei bis drei eigene Fragen vor.

### Die STAR-Methode

Bei verhaltensbezogenen Fragen (_Tell me about a time when ..._) hilft die **STAR-Methode**, eine klare, konkrete Antwort zu geben:

| Schritt          | Inhalt                                   | Beispiel                                                                 |
| ---------------- | ---------------------------------------- | ------------------------------------------------------------------------ |
| **S**ituation    | Ausgangslage                             | `During our diploma project, our database crashed two weeks before the deadline.` |
| **T**ask         | deine Aufgabe                            | `I was responsible for restoring the data.`                              |
| **A**ction       | was du konkret getan hast                | `I restored the last backup, wrote a script to recover the missing entries and set up daily automated backups.` |
| **R**esult       | Ergebnis, möglichst messbar              | `We lost no data and finished on time.`                                  |

### Typische Fragen

| Frage                                                   | Tipp                                                                     |
| ------------------------------------------------------- | ------------------------------------------------------------------------ |
| `Tell me about yourself.`                               | ein bis zwei Minuten: Ausbildung, Erfahrung, warum diese Stelle; kein ganzer Lebenslauf |
| `Why do you want to work for us?`                       | konkreter Bezug auf die Firma                                            |
| `What are your strengths?`                              | zwei Stärken mit Beispiel, passend zur Stelle                            |
| `What is your greatest weakness?`                       | eine echte, nicht zentrale Schwäche und wie du daran arbeitest           |
| `Tell me about a time when you worked in a team.`       | STAR-Methode                                                             |
| `Describe a problem you solved.`                        | STAR-Methode, technische Details verständlich erklären                   |
| `Where do you see yourself in five years?`              | Entwicklung im Fachgebiet, realistisch                                   |
| `Why should we hire you?`                               | Zusammenfassung: Anforderungen und deine passenden Qualifikationen       |
| `Do you have any questions for us?`                     | immer mit Ja antworten und eine Frage stellen                            |

| Eigene Fragen                                                         |
| --------------------------------------------------------------------- |
| What would a typical day in this position look like?                  |
| Which technologies does the team work with?                           |
| How will my work be evaluated during the internship?                  |
| What are the next steps in the application process?                   |

| Nützliche Phrasen                                                     |
| --------------------------------------------------------------------- |
| That's a good question. Let me think for a moment.                    |
| Could you rephrase the question, please?                              |
| For example, in my last internship I ...                              |
| Thank you for taking the time to meet me.                             |
