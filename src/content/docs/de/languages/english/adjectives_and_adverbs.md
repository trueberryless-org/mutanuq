**Adjektive** beschreiben Nomen (`a fast computer`), **Adverbien** beschreiben Verben, Adjektive, andere Adverbien oder ganze Sätze (`It runs fast.`, `extremely fast`, `Fortunately, ...`). Im Deutschen sehen Adjektiv und Adverb oft gleich aus („Er fährt schnell.“), im Englischen meist nicht: `He is a careful driver.` gegenüber `He drives carefully.`

## Adverbien bilden

Die meisten Adverbien entstehen aus Adjektiv + `-ly`.

| Regel                         | Beispiele                                              |
| ----------------------------- | ------------------------------------------------------ |
| Adjektiv + `-ly`              | `quick` → `quickly`, `careful` → `carefully`, `nice` → `nicely` |
| Konsonant + `-y` → `-ily`     | `easy` → `easily`, `happy` → `happily`                 |
| `-le` → `-ly`                 | `simple` → `simply`, `possible` → `possibly`, `gentle` → `gently` |
| `-ic` → `-ically`             | `basic` → `basically`, `automatic` → `automatically` (Ausnahme: `public` → `publicly`) |
| `-ll` → `-lly`                | `full` → `fully`                                       |
| `-ue` → `-uly`                | `true` → `truly`                                       |

### Unregelmäßige Adverbien

| Adjektiv | Adverb   | Hinweis                                                                    |
| -------- | -------- | -------------------------------------------------------------------------- |
| `good`   | `well`   | `She is a good programmer. She codes well.`                                |
| `fast`   | `fast`   | ~~fastly~~ gibt es nicht                                                   |
| `hard`   | `hard`   | `He works hard.`; `hardly` bedeutet „kaum“                                 |
| `late`   | `late`   | `She arrived late.`; `lately` bedeutet „in letzter Zeit“                   |
| `early`  | `early`  | `I got up early.`                                                          |
| `straight`, `daily`, `monthly` | gleich | `Go straight on.`, `a daily backup`, `backed up daily`           |

`well` ist auch ein Adjektiv mit der Bedeutung „gesund“: `I'm not feeling well.`

### Adjektive auf -ly

`friendly`, `lovely`, `lonely`, `silly`, `likely`, `ugly`, `costly` sind **Adjektive** und haben keine Adverbform. Man umschreibt: `She smiled in a friendly way.`

### Adjektiv nach Linking Verbs

Nach Verben, die einen Zustand oder Sinneseindruck beschreiben, steht das **Adjektiv**, weil es das Subjekt beschreibt, nicht die Handlung: `be`, `become`, `get`, `seem`, `appear`, `look`, `sound`, `feel`, `smell`, `taste`, `stay`, `remain`.

-   `That sounds good.` (nicht ~~sounds well~~)
-   `I feel bad about it.`
-   `She looks tired.` gegenüber `She looked carefully at the code.` (hier beschreibt `look` eine Handlung)

### -ed- und -ing-Adjektive

-   `-ed` beschreibt, wie sich jemand **fühlt**: `I'm bored.`, `She is interested in AI.`
-   `-ing` beschreibt, was dieses Gefühl **auslöst**: `The lesson is boring.`, `AI is interesting.`

`I am boring.` heißt „Ich bin langweilig“, nicht „Mir ist langweilig“.

## Steigerung und Vergleiche

| Adjektiv                               | Komparativ                    | Superlativ                        |
| -------------------------------------- | ----------------------------- | --------------------------------- |
| einsilbig                              | `fast` → `faster`             | `the fastest`                     |
| einsilbig auf `-e`                     | `large` → `larger`            | `the largest`                     |
| einsilbig, kurzer Vokal + Konsonant    | `big` → `bigger`, `hot` → `hotter` | `the biggest`                |
| zweisilbig auf `-y`                    | `easy` → `easier`, `happy` → `happier` | `the easiest`            |
| zwei- und mehrsilbig                   | `modern` → `more modern`, `expensive` → `more expensive` | `the most expensive` |
| Adverbien auf `-ly`                    | `quickly` → `more quickly`    | `the most quickly`                |

Einige zweisilbige Adjektive haben beide Formen: `clever`, `narrow`, `quiet`, `simple`, `polite` (`simpler` oder `more simple`).

### Unregelmäßige Steigerung

| Grundform           | Komparativ             | Superlativ                    |
| ------------------- | ---------------------- | ----------------------------- |
| `good` / `well`     | `better`               | `the best`                    |
| `bad` / `badly`     | `worse`                | `the worst`                   |
| `much` / `many`     | `more`                 | `the most`                    |
| `little`            | `less`                 | `the least`                   |
| `far`               | `farther` / `further`  | `the farthest` / `the furthest` |
| `old`               | `older` / `elder`      | `the oldest` / `the eldest`   |

`further` bedeutet auch „weitere, zusätzliche“: `further information`. `elder`/`eldest` verwendet man nur für Familienmitglieder vor dem Nomen: `my elder sister`.

### Vergleichsstrukturen

| Struktur                                  | Beispiel                                                       |
| ----------------------------------------- | -------------------------------------------------------------- |
| Komparativ + `than`                       | `SSDs are faster than HDDs.`                                   |
| `as ... as` (gleich)                      | `This laptop is as fast as mine.`                              |
| `not as/so ... as` (weniger)              | `Java is not as concise as Python.`                            |
| `the` + Komparativ, `the` + Komparativ    | `The more you practise, the better you get.`                   |
| Komparativ + `and` + Komparativ           | `Computers are getting faster and faster.`                     |
| Verstärkung                               | `much/far/a lot faster`, `slightly/a bit faster`               |
| Superlativ + `in` (Ort, Gruppe als Einheit) | `the best student in the class`                              |
| Superlativ + `of` (Mehrzahl)              | `the fastest of all the models`                                |

Nach `than` und `as` steht im neutralen Englisch das Objektpronomen (`She is taller than me.`), im formellen Englisch Subjekt + Verb (`She is taller than I am.`).

:::caution
~~more better~~, ~~more faster~~ und ~~the most best~~ sind falsch: Es wird nur einmal gesteigert. „als“ im Vergleich heißt `than`, nicht ~~then~~ oder ~~as~~.
:::

## Reihenfolge von Adjektiven

Stehen mehrere Adjektive vor einem Nomen, folgen sie meist dieser Reihenfolge (Meinung vor Fakten):

| 1 Meinung | 2 Größe | 3 Alter | 4 Form | 5 Farbe | 6 Herkunft | 7 Material | 8 Zweck/Art | Nomen |
| --------- | ------- | ------- | ------ | ------- | ---------- | ---------- | ----------- | ----- |
| `nice`    | `small` | `old`   | `round`| `black` | `Italian`  | `leather`  | `office`    | chair |

-   `a beautiful old wooden house`
-   `a powerful new gaming laptop`
-   `a small black USB cable`

In der Praxis stehen selten mehr als drei Adjektive vor einem Nomen. Zwischen Adjektiven verschiedener Gruppen steht kein Komma; Adjektive derselben Gruppe trennt man mit Komma oder `and`: `a cheap, reliable laptop`.

## Stellung von Adverbien

Adverbien können am Satzanfang (_front position_), in der Satzmitte (_mid position_) oder am Satzende (_end position_) stehen.

| Art                         | Position                                                    | Beispiel                                                   |
| --------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| Häufigkeit (`always`, `usually`, `often`, `never`) | Mitte: vor dem Vollverb, nach `be` und nach dem ersten Hilfsverb | `I usually start at 8.` / `She is always late.` / `I have never seen it.` |
| Art und Weise (`carefully`, `quickly`) | meist am Ende, nach dem Objekt                    | `He checked the code carefully.`                           |
| Ort (`here`, `at home`)     | Ende                                                        | `I'll wait here.`                                          |
| Zeit (`yesterday`, `soon`)  | Ende oder Anfang                                            | `I'll call you tomorrow.` / `Tomorrow I'll call you.`      |
| Satzadverbien (`fortunately`, `obviously`, `however`) | meist Anfang mit Komma            | `Fortunately, nobody was hurt.`                            |
| Gradadverbien (`very`, `extremely`, `quite`) | vor dem Adjektiv oder Adverb       | `extremely fast`                                           |
| Fokusadverbien (`only`, `even`, `also`, `just`) | Mitte oder vor dem betonten Wort | `I only need five minutes.`                               |

Zwischen Verb und Objekt steht kein Adverb: ~~She speaks very well English.~~ Richtig: `She speaks English very well.`

## Verwechslungsgefahr

| Wortpaar                         | Bedeutung und Beispiel                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| `hard` / `hardly`                | hart, fleißig / kaum: `I work hard.`, `I can hardly hear you.`                       |
| `late` / `lately`                | spät / in letzter Zeit: `Have you seen him lately?`                                  |
| `near` / `nearly`                | nahe / beinahe: `I nearly missed the bus.`                                           |
| `high` / `highly`                | hoch (räumlich) / sehr: `The plane flew high.`, `highly recommended`                 |
| `most` / `mostly`                | die meisten / hauptsächlich: `Most users are students.`, `The users are mostly students.` |
| `short` / `shortly`              | kurz / bald: `I'll be there shortly.`                                                |
| `quite` / `quiet`                | ziemlich / leise                                                                     |
| `so` / `such`                    | `so` + Adjektiv, `such (a)` + (Adjektiv +) Nomen: `so fast`, `such a fast laptop`    |
| `too` / `enough`                 | `too` vor dem Adjektiv, `enough` danach (aber vor Nomen): `too slow`, `fast enough`, `enough memory` |
| `economic` / `economical`        | die Wirtschaft betreffend / sparsam                                                  |
| `historic` / `historical`        | historisch bedeutend / die Geschichte betreffend                                     |
| `electric` / `electrical` / `electronic` | elektrisch betrieben / die Elektrik betreffend / elektronisch            |
| `sensible` / `sensitive`         | vernünftig / empfindlich, sensibel                                                   |
| `fun` / `funny`                  | macht Spaß / lustig, komisch                                                         |
