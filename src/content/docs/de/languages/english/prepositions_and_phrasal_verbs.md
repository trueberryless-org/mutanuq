Präpositionen lassen sich selten eins zu eins übersetzen: „am Montag“ ist `on Monday`, „am Bahnhof“ ist `at the station`, „im Internet“ ist `on the internet`. Viele Präpositionen gehören zu festen Wendungen (_collocations_) und müssen mit dem Wort gelernt werden. **Phrasal Verbs** sind Verben mit einer Partikel (`set up`, `log in`), deren Bedeutung sich oft nicht aus den Einzelteilen ergibt.

## Präpositionen der Zeit

| Präposition | Verwendung                                                       | Beispiele                                                   |
| ----------- | ---------------------------------------------------------------- | ----------------------------------------------------------- |
| `at`        | Uhrzeit, Zeitpunkt, Feiertage als Zeitraum, Wochenende (BrE)     | `at 8 o'clock`, `at noon`, `at night`, `at Christmas`, `at the weekend` (AmE `on the weekend`), `at the moment` |
| `on`        | Tage, Datum, bestimmter Tagesteil                                | `on Monday`, `on 5 May`, `on my birthday`, `on Friday evening` |
| `in`        | Monate, Jahre, Jahreszeiten, Jahrhunderte, Tagesteile, Zeitraum bis etwas geschieht | `in May`, `in 2024`, `in winter`, `in the 21st century`, `in the morning`, `in two weeks` (= nach zwei Wochen) |

Ohne Präposition stehen `this`, `next`, `last`, `every`, `today`, `tomorrow`, `yesterday`: `I'll see you next Monday.` (nicht ~~on next Monday~~)

### Weitere Zeitpräpositionen

| Präposition                | Bedeutung                                        | Beispiel                                              |
| -------------------------- | ------------------------------------------------ | ----------------------------------------------------- |
| `for`                      | Dauer („seit“, „lang“)                           | `for three years`                                     |
| `since`                    | Zeitpunkt („seit“)                               | `since 2020`                                          |
| `ago`                      | vor (von jetzt aus, nachgestellt)                | `two days ago`                                        |
| `during`                   | während (+ Nomen)                                | `during the meeting`                                  |
| `while`                    | während (+ Satz)                                 | `while I was working`                                 |
| `by`                       | bis spätestens                                   | `Please send it by Friday.`                           |
| `until`, `till`            | bis (andauernd)                                  | `I'll be in the office until 5 pm.`                   |
| `within`                   | innerhalb                                        | `within 24 hours`                                     |
| `on time` / `in time`      | pünktlich / rechtzeitig                          | `The train was on time.` / `We arrived in time for the start.` |

:::caution[bis: by oder until]
`by` bedeutet „spätestens bis“ (eine Handlung ist bis dann erledigt), `until` bedeutet „die ganze Zeit bis“ (ein Zustand dauert an): `Finish the report by Friday.` gegenüber `I'll work on it until Friday.`
:::

## Präpositionen des Ortes

| Präposition | Verwendung                                       | Beispiele                                                              |
| ----------- | ------------------------------------------------ | ---------------------------------------------------------------------- |
| `at`        | Punkt, Ort als Treffpunkt oder Funktion          | `at the station`, `at the door`, `at the bus stop`, `at school`, `at work`, `at home`, `at the top`, `at a conference` |
| `in`        | innerhalb eines Raumes oder Gebiets              | `in the room`, `in the box`, `in Vienna`, `in Austria`, `in the car`, `in a taxi`, `in the picture`, `in the photo` |
| `on`        | auf einer Fläche, Linie, öffentliche Verkehrsmittel, Medien | `on the desk`, `on the wall`, `on the first floor`, `on the bus`, `on the train`, `on the internet`, `on the website`, `on page 5`, `on the screen`, `on TV` |

### Bewegung und Richtung

| Präposition         | Bedeutung                     | Beispiel                                       |
| ------------------- | ----------------------------- | ---------------------------------------------- |
| `to`                | zu, nach                      | `go to Vienna`, `send it to me`                |
| `into` / `out of`   | in etwas hinein / heraus      | `Plug the cable into the port.`                |
| `onto`              | auf etwas hinauf              | `Drag the file onto the desktop.`              |
| `through`           | durch                         | `The data passes through the firewall.`        |
| `across`            | über, quer hinüber            | `walk across the street`                       |
| `along`             | entlang                       | `along the river`                              |
| `past`              | vorbei                        | `go past the school`                           |
| `towards`           | in Richtung                   | `walk towards the exit`                        |

`arrive` steht mit `at` (Gebäude, Ort) oder `in` (Stadt, Land), nie mit `to`: `We arrived in London.`, `She arrived at the airport.` Bei `home` gibt es keine Präposition: `go home`, `arrive home`.

## Feste Verbindungen

### Verb + Präposition

| Verbindung                | Beispiel                                          |
| ------------------------- | ------------------------------------------------- |
| `agree with` sb / `on` sth | `I agree with you.` / `We agreed on a deadline.` |
| `apply for` (Stelle) / `apply to` (Firma) | `I applied to Google for an internship.` |
| `ask for`                 | `ask for help`                                    |
| `consist of`              | `The team consists of five people.`               |
| `deal with`               | `deal with a problem`                             |
| `depend on`, `rely on`    | `It depends on the budget.`                       |
| `focus on`                | `focus on the main points`                        |
| `listen to`               | `listen to a podcast`                             |
| `pay for`                 | `pay for the licence`                             |
| `result in` / `result from` | `The bug resulted in data loss.`                |
| `succeed in`              | `succeed in fixing the bug`                       |
| `take part in`            | `take part in a competition`                      |
| `wait for`                | `wait for a response`                             |

Ohne Präposition stehen: `discuss` (nicht ~~discuss about~~), `enter` (nicht ~~enter into~~ einen Raum), `call` (jemanden anrufen), `answer`, `reach`, `contact`, `lack`.

### Adjektiv + Präposition

| Verbindung                         | Beispiel                                            |
| ---------------------------------- | --------------------------------------------------- |
| `afraid of`, `aware of`, `capable of`, `proud of`, `tired of` | `I'm aware of the risk.`  |
| `good at`, `bad at`                | `She's good at maths.`                              |
| `interested in`                    | `interested in robotics`                            |
| `responsible for`                  | `responsible for the network`                       |
| `different from` (BrE auch `to`)   | `Rust is different from C.`                         |
| `similar to`                       | `similar to Java`                                   |
| `angry with` sb / `about` sth      | `angry with my brother`                             |
| `keen on`                          | `keen on gaming`                                    |
| `based on`                         | `based on a survey`                                 |
| `familiar with`                    | `familiar with Linux`                               |

### Feste Wendungen

| Wendung                   | Bedeutung                     |
| ------------------------- | ----------------------------- |
| `on purpose`              | absichtlich                   |
| `by mistake`, `by accident` | versehentlich               |
| `by chance`               | zufällig                      |
| `in advance`              | im Voraus                     |
| `in my opinion`           | meiner Meinung nach           |
| `at least`, `at first`, `at last` | mindestens, zuerst, endlich |
| `out of order`            | außer Betrieb                 |
| `on average`              | im Durchschnitt               |
| `in charge of`            | verantwortlich für            |
| `up to date`, `out of date` | aktuell, veraltet           |

## Phrasal Verbs

Ein Phrasal Verb besteht aus einem Verb und einer oder zwei Partikeln (`up`, `out`, `off`, `on`, `in`, `down`, `over`, ...). Die Bedeutung ist oft idiomatisch: `give up` heißt „aufgeben“, `put off` „verschieben“.

### Trennbar oder untrennbar

-   **trennbar** (_separable_): Ein Nomen als Objekt kann vor oder nach der Partikel stehen, ein **Pronomen muss dazwischen**: `Turn off the computer.` = `Turn the computer off.` → `Turn it off.` (nicht ~~Turn off it.~~)
-   **untrennbar** (_inseparable_): Das Objekt steht immer nach der Partikel: `I'll look after the kids.` → `I'll look after them.`
-   **dreiteilig**: immer untrennbar: `I'm looking forward to it.`, `We ran out of memory.`

### Wichtige Phrasal Verbs im Alltag und Beruf

| Phrasal Verb        | Bedeutung                                | Beispiel                                          |
| ------------------- | ---------------------------------------- | ------------------------------------------------- |
| `bring up`          | ansprechen (Thema)                       | `She brought up an interesting point.`            |
| `call off`          | absagen                                  | `The meeting was called off.`                     |
| `carry out`         | durchführen                              | `carry out a survey`                              |
| `come up with`      | sich ausdenken                           | `come up with a solution`                         |
| `deal with`         | sich kümmern um                          | `deal with complaints`                            |
| `figure out`        | herausfinden, verstehen                  | `I can't figure out the error.`                   |
| `fill in` / `fill out` | ausfüllen                             | `fill in the form`                                |
| `find out`          | herausfinden                             | `find out the cause`                              |
| `get along with`    | auskommen mit                            | `I get along with my colleagues.`                 |
| `give up`           | aufgeben                                 | `Don't give up.`                                  |
| `go on`             | weitermachen, passieren                  | `What's going on?`                                |
| `look after`        | sich kümmern um                          | `look after the servers`                          |
| `look into`         | untersuchen                              | `We'll look into the problem.`                    |
| `look up`           | nachschlagen                             | `look up a word`                                  |
| `point out`         | hinweisen auf                            | `point out a mistake`                             |
| `put off`           | verschieben                              | `Don't put it off.`                               |
| `put up with`       | sich gefallen lassen, ertragen           | `put up with slow Wi-Fi`                          |
| `run out of`        | ausgehen, knapp werden                   | `We ran out of disk space.`                       |
| `set up`            | einrichten, gründen                      | `set up a company`, `set up a router`             |
| `sort out`          | klären, in Ordnung bringen               | `sort out a problem`                              |
| `take over`         | übernehmen                               | `take over a project`                             |
| `turn down`         | ablehnen, leiser stellen                 | `turn down an offer`                              |

### Phrasal Verbs in der IT

| Phrasal Verb               | Bedeutung                                     | Beispiel                                             |
| -------------------------- | --------------------------------------------- | ---------------------------------------------------- |
| `back up`                  | sichern                                       | `Back up your files regularly.`                      |
| `boot up`, `start up`      | hochfahren                                    | `The PC takes ages to boot up.`                      |
| `shut down`                | herunterfahren                                | `Shut down the server before maintenance.`           |
| `log in`, `log on`         | anmelden                                      | `Log in with your school account.`                   |
| `log out`, `log off`       | abmelden                                      | `Don't forget to log out.`                           |
| `sign up`                  | registrieren                                  | `sign up for a free account`                         |
| `plug in`                  | anstecken                                     | `Plug in the charger.`                               |
| `set up`                   | einrichten, konfigurieren                     | `set up a VPN`                                       |
| `roll out`                 | ausrollen, einführen                          | `roll out an update`                                 |
| `roll back`                | zurücksetzen                                  | `roll back to the previous version`                  |
| `scale up` / `scale out`   | vertikal / horizontal skalieren               | `scale out the web servers`                          |
| `free up`                  | freimachen                                    | `free up disk space`                                 |
| `clean up`                 | aufräumen                                     | `clean up the code`                                  |
| `print out`                | ausdrucken                                    | `print out the invoice`                              |
| `zoom in` / `zoom out`     | hinein- / herauszoomen                        | `Zoom in on the chart.`                              |
| `scroll down` / `scroll up` | nach unten / oben scrollen                   | `Scroll down to the bottom.`                         |
| `key in`, `type in`        | eintippen                                     | `Type in your password.`                             |
| `break down`               | ausfallen; aufschlüsseln                      | `The system broke down.`, `break down the costs`     |
| `time out`                 | wegen Zeitüberschreitung abbrechen            | `The connection timed out.`                          |
| `opt in` / `opt out`       | zustimmen / ablehnen                          | `opt out of tracking`                                |
| `phase out`                | schrittweise abschaffen                       | `phase out Windows 10`                               |
| `lock out`                 | aussperren                                    | `I locked myself out of my account.`                 |

:::tip[Verb oder Nomen]
Viele IT-Begriffe sind als Verb zwei Wörter, als Nomen oder Adjektiv ein Wort: `to log in` / `the login page`, `to back up` / `a backup`, `to set up` / `the setup`, `to shut down` / `a shutdown`, `to start up` / `a startup`, `to sign up` / `a signup form`. Richtig ist also `Please log in.`, aber `Enter your login details.`
:::
