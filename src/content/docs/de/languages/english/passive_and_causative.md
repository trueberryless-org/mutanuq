Im Aktiv steht der Handelnde im Vordergrund (`The admin installs the update.`), im Passiv die Handlung oder das Objekt, mit dem etwas geschieht (`The update is installed.`). Das Passiv verwendest du, wenn der Handelnde unbekannt, unwichtig oder selbstverständlich ist, und in sachlichen Texten wie [Berichten](/de/languages/text_types/report/), Protokollen und technischen Beschreibungen.

## Bildung

Das Passiv wird mit einer Form von **`be`** + **Partizip Perfekt** (3. Form) gebildet. Die Zeitform steckt immer im Hilfsverb `be`; das Partizip bleibt gleich. Das Objekt des Aktivsatzes wird zum Subjekt des Passivsatzes.

| Zeitform                   | Aktiv                                  | Passiv                                     |
| -------------------------- | -------------------------------------- | ------------------------------------------ |
| Present Simple             | They **test** the code.                | The code **is tested**.                    |
| Present Progressive        | They **are testing** the code.         | The code **is being tested**.              |
| Present Perfect            | They **have tested** the code.         | The code **has been tested**.              |
| Past Simple                | They **tested** the code.              | The code **was tested**.                   |
| Past Progressive           | They **were testing** the code.        | The code **was being tested**.             |
| Past Perfect               | They **had tested** the code.          | The code **had been tested**.              |
| Future Simple              | They **will test** the code.           | The code **will be tested**.               |
| Future Perfect             | They **will have tested** the code.    | The code **will have been tested**.        |
| going to                   | They **are going to test** the code.   | The code **is going to be tested**.        |
| Modalverb                  | They **must test** the code.           | The code **must be tested**.               |
| Modalverb Perfekt          | They **should have tested** the code.  | The code **should have been tested**.      |
| Infinitiv                  | I want them **to test** it.            | I want it **to be tested**.                |
| Gerundium                  | I don't like people **criticising** me. | I don't like **being criticised**.        |

Die Perfect-Progressive-Formen und das Future Progressive (`will be being tested`) sind im Passiv grammatisch möglich, klingen aber schwerfällig und werden praktisch nicht verwendet.

Verneinung und Frage bildest du mit dem ersten Hilfsverb: `The code wasn't tested.`, `Has the code been tested?`

:::caution
Nur Verben mit Objekt (transitive Verben) haben ein Passiv. `happen`, `arrive`, `die`, `occur` haben keines: ~~The accident was happened.~~ Richtig: `The accident happened.`
:::

## by-agent

Der Handelnde (_agent_) wird mit `by` angeschlossen, aber nur, wenn er wichtig oder neu ist.

-   `The World Wide Web was invented by Tim Berners-Lee.` (Information ist wichtig.)
-   `My bike was stolen.` (Täter unbekannt, kein `by someone`.)
-   `The suspect was arrested.` (Selbstverständlich durch die Polizei, kein `by the police`.)

Das Mittel oder Werkzeug wird mit `with` angeschlossen: `The file was encrypted with AES.`

## Passiv mit zwei Objekten

Verben wie `give`, `send`, `show`, `offer`, `tell`, `teach`, `lend`, `pay` haben ein indirektes Objekt (Person) und ein direktes Objekt (Sache). Beide können Subjekt des Passivsatzes werden.

| Aktiv                                       | Passiv mit Person als Subjekt (häufiger)     | Passiv mit Sache als Subjekt                    |
| ------------------------------------------- | -------------------------------------------- | ----------------------------------------------- |
| They gave **me** **a new laptop**.          | **I** was given a new laptop.                | **A new laptop** was given to me.               |
| The company offered **her** **a job**.      | **She** was offered a job.                   | **A job** was offered to her.                   |

Das Passiv mit der Person als Subjekt ist im Englischen üblicher und hat keine direkte deutsche Entsprechung („Mir wurde ein Laptop gegeben.“).

## Passiv mit Präpositionalverben

Bei Verben mit Präposition bleibt die Präposition nach dem Partizip stehen.

-   `Somebody must deal with the problem.` wird zu `The problem must be dealt with.`
-   `Everybody laughed at him.` wird zu `He was laughed at.`
-   `They looked after the servers well.` wird zu `The servers were looked after well.`

## Unpersönliches Passiv

Mit Verben des Sagens und Meinens (`say`, `believe`, `think`, `know`, `report`, `expect`, `consider`, `claim`, `estimate`) gibst du allgemeine Meinungen oder Berichte wieder, ohne eine Quelle zu nennen. Das ist typisch für Nachrichten, Berichte und Essays. Es gibt zwei Konstruktionen:

| Aktiv                                      | `It is said that ...`                          | Persönliche Konstruktion                         |
| ------------------------------------------ | ---------------------------------------------- | ------------------------------------------------ |
| People say that he is a genius.            | It is said that he is a genius.                | He **is said to be** a genius.                   |
| People believe that the hacker lives in Asia. | It is believed that the hacker lives in Asia. | The hacker **is believed to live** in Asia.     |
| Experts think the attack started last week. | It is thought that the attack started last week. | The attack **is thought to have started** last week. |
| They report that the CEO is negotiating.   | It is reported that the CEO is negotiating.    | The CEO **is reported to be negotiating**.       |

Bei der persönlichen Konstruktion hängt der Infinitiv von der Zeit des Nebensatzes ab:

-   gleichzeitig: `to be`, `to do` (`He is said to be rich.`)
-   gleichzeitig, im Verlauf: `to be doing` (`She is believed to be working on a new app.`)
-   vorzeitig: `to have done` (`He is said to have earned millions.`)

Nach `there` gibt es eine eigene Form: `There are said to be more than 8 billion people on Earth.`

## Causative: have/get something done

Mit dem **Causative** drückst du aus, dass du etwas **machen lässt**, also nicht selbst tust, sondern jemanden beauftragst.

**Bildung:** `have` oder `get` + Objekt + Partizip Perfekt. `have` ist etwas formeller, `get` umgangssprachlicher. Die Zeitform steckt in `have/get`.

| Satz                                                   | Bedeutung                                                   |
| ------------------------------------------------------ | ----------------------------------------------------------- |
| `I repaired my laptop.`                                | Ich habe ihn selbst repariert.                              |
| `I had my laptop repaired.`                            | Ich habe ihn reparieren lassen.                             |
| `We are having the network upgraded next week.`        | Wir lassen nächste Woche das Netzwerk aufrüsten.            |
| `You should get your eyes tested.`                     | Du solltest deine Augen untersuchen lassen.                 |
| `She has just had her hair cut.`                       | Sie hat sich gerade die Haare schneiden lassen.             |

`have something done` beschreibt auch **unangenehme Erlebnisse**, die einem passiert sind: `I had my phone stolen on the train.` (Mir wurde im Zug das Handy gestohlen.)

### Weitere Causative-Strukturen

| Struktur                                      | Beispiel                                                  |
| --------------------------------------------- | --------------------------------------------------------- |
| `have` + Person + Grundform                   | `I'll have the technician check the printer.`            |
| `get` + Person + `to` + Grundform             | `I got my brother to install the software.`              |
| `make` + Person + Grundform (zwingen)         | `The teacher made us rewrite the essay.`                 |
| `let` + Person + Grundform (erlauben)         | `My parents let me use their car.`                       |

Im Passiv bekommt `make` ein `to`: `We were made to rewrite the essay.`

## Passiv in technischen Texten

In Beschreibungen von Abläufen und Systemen steht das Passiv im Present Simple, weil das Gerät oder die Daten wichtiger sind als die Person.

> When a user logs in, the password is hashed and compared with the stored hash. If the values match, a session token is created and sent to the browser.

Übertreib das Passiv aber nicht: Anleitungen schreibst du im Imperativ (`Click Save.`) und in E-Mails wirkt das Aktiv persönlicher.
