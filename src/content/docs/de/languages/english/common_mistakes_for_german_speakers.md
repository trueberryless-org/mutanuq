Deutsch und Englisch sind eng verwandt. Das hilft beim Lernen, führt aber auch zu systematischen Fehlern: Wörter sehen gleich aus und bedeuten etwas anderes, deutsche Satzstellung und Zeitformen werden übertragen und deutsche Komma- und Großschreibregeln landen im englischen Text. Diese Fehler kosten bei der Matura Punkte im Kriterium _Lexical and Structural Accuracy_.

## False Friends

**False Friends** sind Wortpaare, die in beiden Sprachen ähnlich aussehen, aber unterschiedliche Bedeutungen haben.

| Englisch        | bedeutet                       | Deutsch          | heißt auf Englisch                    |
| --------------- | ------------------------------ | ---------------- | ------------------------------------- |
| `become`        | werden                         | bekommen         | `get`, `receive`                      |
| `actual`        | tatsächlich, eigentlich        | aktuell          | `current`, `up to date`, `latest`     |
| `actually`      | eigentlich, tatsächlich        | aktuell (Adv.)   | `currently`, `at the moment`          |
| `eventually`    | schließlich, endlich           | eventuell        | `possibly`, `perhaps`                 |
| `also`          | auch                           | also             | `so`, `therefore`                     |
| `sensible`      | vernünftig                     | sensibel         | `sensitive`                           |
| `sympathetic`   | mitfühlend                     | sympathisch      | `nice`, `likeable`                    |
| `consequent`    | (daraus) folgend               | konsequent       | `consistent`                          |
| `chef`          | Koch, Köchin                   | Chef             | `boss`, `manager`, `head`             |
| `gift`          | Geschenk                       | Gift             | `poison`                              |
| `handy`         | praktisch, griffbereit         | Handy            | `mobile (phone)` (BrE), `cell phone` (AmE) |
| `map`           | Landkarte                      | Mappe            | `folder`, `binder`                    |
| `beamer`        | umgangssprachlich: BMW         | Beamer           | `projector`                           |
| `oldtimer`      | alter Hase, ältere Person      | Oldtimer         | `vintage car`, `classic car`          |
| `public viewing` | Aufbahrung (eines Toten)      | Public Viewing   | `open-air screening`, `fan zone`      |
| `home office`   | Arbeitszimmer; in GB: Innenministerium | Homeoffice | `working from home`, `remote work`    |
| `undertaker`    | Bestatter                      | Unternehmer      | `entrepreneur`                        |
| `bald`          | glatzköpfig                    | bald             | `soon`                                |
| `brave`         | mutig                          | brav             | `well-behaved`, `good`                |
| `fabric`        | Stoff                          | Fabrik           | `factory`                             |
| `art`           | Kunst                          | Art              | `kind`, `type`, `way`                 |
| `control`       | steuern, beherrschen           | kontrollieren    | `check`, `inspect`                    |
| `engagement`    | Verlobung; Termin              | Engagement       | `commitment`, `involvement`           |
| `provision`     | Bereitstellung, Vorrat         | Provision        | `commission`                          |
| `pension`       | Rente, Pension (Ruhegeld)      | Pension (Gasthaus) | `guesthouse`, `B&B`                 |
| `note`          | Notiz                          | Note (Schulnote) | `mark` (BrE), `grade` (AmE)           |
| `meaning`       | Bedeutung                      | Meinung          | `opinion`                             |
| `spend`         | ausgeben (Geld, Zeit)          | spenden          | `donate`                              |
| `will` (Hilfsverb) | werden (Zukunft)            | ich will         | `I want`                              |
| `who`           | wer                            | wo               | `where`                               |
| `where`         | wo                             | wer              | `who`                                 |
| `mobbing`       | (selten) Bedrängen durch eine Menge | Mobbing     | `bullying`                            |

:::caution[wenn: when oder if]
Deutsches „wenn“ hat zwei Entsprechungen: `when` für etwas, das sicher eintritt (`When I get home, I'll call you.`), `if` für eine Bedingung (`If I get the job, I'll move to Vienna.`).
:::

### Verwechslungspaare

| Wortpaar                  | Unterschied                                                                 |
| ------------------------- | --------------------------------------------------------------------------- |
| `make` / `do`             | `make` = herstellen, erschaffen (`make a mistake`, `make a decision`, `make a phone call`, `make progress`); `do` = Tätigkeit, Arbeit (`do homework`, `do research`, `do a course`, `do business`) |
| `take` / `make` a photo   | `take a photo` (nicht ~~make a photo~~)                                     |
| `say` / `tell`            | `tell a lie`, `tell the truth`, `tell a story`, `tell somebody`; `say something` |
| `lend` / `borrow`         | `lend` = (ver)leihen, `borrow` = sich ausleihen: `Can you lend me your pen?` / `Can I borrow your pen?` |
| `learn` / `teach`         | `learn` = lernen, `teach` = lehren: ~~He learned me English.~~ → `He taught me English.` |
| `rise` / `raise`          | `rise` = steigen (ohne Objekt), `raise` = erhöhen (mit Objekt): `Prices rise.`, `They raised prices.` |
| `lie` / `lay`             | `lie` (lay, lain) = liegen, `lay` (laid, laid) = legen                      |
| `possibility` / `opportunity` | `possibility` = Möglichkeit (etwas könnte sein), `opportunity` = Gelegenheit, Chance: `a job opportunity` |
| `last` / `latest`         | `last` = letzte (danach kommt nichts mehr), `latest` = neueste: `the latest version` |
| `most` / `the most`       | „die meisten Leute“ = `most people` (nicht ~~the most people~~)             |

## Typische Grammatikfehler

| Falsch                                        | Richtig                                         | Regel                                                      |
| --------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------------- |
| ~~I live here since three years.~~            | `I have lived here for three years.`            | Present Perfect bei „seit“; `for` + Dauer                  |
| ~~Yesterday I have seen him.~~                | `Yesterday I saw him.`                          | abgeschlossene Zeit → Past Simple                          |
| ~~If I will have time, I will come.~~         | `If I have time, I will come.`                  | kein `will` im if-Satz                                     |
| ~~If I would have known, ...~~                | `If I had known, ...`                           | Third Conditional mit Past Perfect                         |
| ~~He go to school.~~ / ~~He don't know.~~     | `He goes to school.` / `He doesn't know.`       | `-s` in der 3. Person Singular                             |
| ~~I am agree.~~                               | `I agree.`                                      | `agree` ist ein Verb                                       |
| ~~Can you explain me ...?~~                   | `Can you explain to me ...?` / `Can you explain ...?` | `explain something to somebody`                      |
| ~~We discussed about the problem.~~           | `We discussed the problem.`                     | `discuss` ohne Präposition                                 |
| ~~It gives many problems.~~                   | `There are many problems.`                      | „es gibt“ = `there is/are`                                 |
| ~~The life is beautiful.~~                    | `Life is beautiful.`                            | kein Artikel bei allgemeiner Bedeutung                     |
| ~~She is teacher.~~                           | `She is a teacher.`                             | Artikel bei Berufen                                        |
| ~~informations~~, ~~advices~~                 | `information`, `advice`                         | nicht zählbar                                              |
| ~~The people is nice.~~                       | `The people are nice.`                          | `people` ist Plural                                        |
| ~~I look forward to hear from you.~~          | `I look forward to hearing from you.`           | `to` ist hier Präposition                                  |
| ~~He suggested me to go.~~                    | `He suggested that I (should) go.`              | Muster von `suggest`                                       |
| ~~more better~~                               | `better`                                        | nur einmal steigern                                        |
| ~~I like very much pizza.~~                   | `I like pizza very much.`                       | kein Adverb zwischen Verb und Objekt                       |
| ~~Do you can help me?~~                       | `Can you help me?`                              | kein `do` bei Modalverben                                  |
| ~~Since when are you here?~~                  | `How long have you been here?`                  | Frage nach Dauer                                           |
| ~~I have a question to you.~~                 | `I have a question for you.`                    | `a question for somebody`                                  |
| ~~until Friday~~ (Frist)                      | `by Friday`                                     | „bis spätestens“ = `by`                                    |

## Zeichensetzung

### Kommas

Das Deutsche setzt Kommas nach grammatischen Regeln vor fast jeden Nebensatz. Das Englische setzt Kommas sparsamer und eher nach Sinn und Lesefluss.

| Situation                                        | Deutsch                                          | Englisch                                         |
| ------------------------------------------------ | ------------------------------------------------ | ------------------------------------------------ |
| vor `that`-Satz                                  | Ich denke, dass ...                              | `I think that ...` (kein Komma)                  |
| vor notwendigem Relativsatz                      | Der Mann, der dort steht, ...                    | `The man who is standing there ...` (kein Komma) |
| vor indirekter Frage                             | Ich weiß nicht, ob ...                           | `I don't know if ...` (kein Komma)               |
| vor Infinitiv                                    | Ich habe vor, ... zu lernen.                     | `I plan to learn ...` (kein Komma)               |
| Nebensatz am Satzende                            | ..., weil ...                                    | `... because ...` (meist kein Komma)             |
| Nebensatz am Satzanfang                          | Wenn ..., ...                                    | `If ..., ...` (Komma)                            |
| nach einleitenden Ausdrücken                     | Leider ist ...                                   | `Unfortunately, ...`, `However, ...`, `In my opinion, ...` (Komma) |
| nicht notwendiger Relativsatz, Einschub          | Mein Bruder, der in Graz lebt, ...               | `My brother, who lives in Graz, ...` (Kommas)    |

Das **Serial Comma** (_Oxford comma_) vor dem letzten `and` einer Aufzählung (`HTML, CSS, and JavaScript`) ist im amerikanischen Englisch üblich und im britischen optional. Verwende es einheitlich.

Zwei vollständige Hauptsätze dürfen nicht nur mit einem Komma verbunden werden (_comma splice_): ~~The server crashed, we lost data.~~ Richtig: `The server crashed, and we lost data.`, `The server crashed; we lost data.` oder zwei Sätze.

### Weitere Unterschiede

| Bereich                   | Deutsch                       | Englisch                                                    |
| ------------------------- | ----------------------------- | ----------------------------------------------------------- |
| Anführungszeichen         | „...“                         | “...” oder britisch oft ‘...’                               |
| Dezimaltrennzeichen       | 3,5                           | `3.5`                                                       |
| Tausendertrennzeichen     | 3.000 oder 3 000              | `3,000`                                                     |
| Anrede in Briefen         | Sehr geehrte Frau Huber!      | `Dear Ms Huber,` (Komma, danach Großbuchstabe)              |
| Datum                     | 20.01.2024                    | `20 January 2024` (BrE), `January 20, 2024` (AmE)           |
| Apostroph                 | selten                        | Besitz und Kurzformen, **nicht** für Plural: `CDs`, `PCs` (nicht ~~PC's~~) |

## Groß- und Kleinschreibung

Im Englischen werden **Nomen kleingeschrieben**, außer sie sind Eigennamen. Großgeschrieben werden:

-   das Pronomen `I`, immer: `Yesterday I ...`
-   Satzanfänge
-   Namen von Personen, Orten, Firmen, Produkten: `Anna`, `Vienna`, `Microsoft`, `Linux`
-   **Wochentage und Monate**: `Monday`, `January` (Jahreszeiten nicht: `in summer`)
-   **Nationalitäten, Sprachen und Adjektive davon**: `Austrian`, `English`, `a German car`
-   Feiertage, Ereignisse: `Christmas`, `World War II`
-   Titel vor Namen: `Professor Smith`, `Dr Huber`
-   Überschriften und Werktitel im _Title Case_ (alle wichtigen Wörter groß): `The Lord of the Rings`; viele Websites und Firmen verwenden für Überschriften auch _Sentence case_.

Schulfächer schreibt man klein (`maths`, `physics`), außer es sind Sprachen (`English`, `German`). `internet` und `email` werden heute meist kleingeschrieben.
