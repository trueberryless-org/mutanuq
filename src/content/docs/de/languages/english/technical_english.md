Dazu gehören der Fachwortschatz, das Beschreiben von Abläufen und Daten und die typischen Kommunikationssituationen im Beruf.

## Abläufe beschreiben

Für die Beschreibung von Prozessen (wie funktioniert etwas, wie läuft etwas ab) verwendest du:

-   das **Present Simple**, weil der Ablauf allgemein gilt
-   oft das **Passiv**, weil das System wichtiger ist als die Person (siehe [Passiv](/de/languages/english/passive_and_causative/#passiv-in-technischen-texten))
-   **Sequenzwörter**: `first`, `then`, `next`, `after that`, `once`, `as soon as`, `finally`
-   **Ursache und Wirkung**: `causes`, `results in`, `leads to`, `as a result`, `so that`

> When you enter a URL, the browser first sends a request to a DNS server, which returns the IP address of the web server. Next, a TCP connection is established and the browser sends an HTTP request. The server then processes the request and sends back a response. Finally, the page is rendered by the browser.

### Entwicklungen beschreiben

| Richtung          | Verben                                         | Nomen                                    |
| ----------------- | ---------------------------------------------- | ---------------------------------------- |
| nach oben         | `rise`, `increase`, `grow`, `go up`, `climb`   | `a rise`, `an increase`, `growth`        |
| nach unten        | `fall`, `decrease`, `decline`, `drop`, `go down` | `a fall`, `a decrease`, `a decline`, `a drop` |
| gleich bleibend   | `remain stable`, `stay the same`, `level off`  | `a plateau`                              |
| schwankend        | `fluctuate`                                    | `a fluctuation`                          |
| Höchst-/Tiefstwert | `peak at`, `reach a peak`, `hit a low`        | `a peak`, `a low point`                  |

| Stärke            | Adjektiv (+ Nomen)        | Adverb (+ Verb)             |
| ----------------- | ------------------------- | --------------------------- |
| stark, plötzlich  | `sharp`, `dramatic`, `steep`, `sudden` | `sharply`, `dramatically`, `steeply`, `suddenly` |
| deutlich          | `significant`, `considerable` | `significantly`, `considerably` |
| gleichmäßig       | `steady`, `gradual`       | `steadily`, `gradually`     |
| leicht            | `slight`, `small`         | `slightly`                  |

**Präpositionen** sind bei Zahlen entscheidend:

-   `rose from 20 % to 35 %` (Ausgangs- und Endwert)
-   `rose by 15 percentage points` (Differenz)
-   `stood at 2 million` (Wert zu einem Zeitpunkt)
-   `a rise of 10 %` (Nomen + `of`)

> The line graph shows the number of registered users of our school app between 2020 and 2025. The number rose steadily from 400 to 1,150. The sharpest increase occurred between 2022 and 2023, when the app was introduced in all classes.

Beachte die englische Zahlenschreibweise mit Dezimalpunkt und Tausenderkomma.

## Technische Dokumentation

Gute technische Dokumentation (Anleitungen, README-Dateien, Handbücher) ist für die Leser geschrieben, die etwas erledigen wollen. Daraus ergeben sich diese Regeln:

-   **Zielgruppe** festlegen: Endbenutzer brauchen andere Informationen als Entwickler.
-   **Anleitungen im Imperativ**, ein Schritt pro Satz, nummeriert: `1. Open the terminal. 2. Run the install script.`
-   **Aktiv und Present Simple**, kurze Sätze, keine Füllwörter
-   **einheitliche Begriffe**: einmal `folder`, dann nicht plötzlich `directory`
-   Hinweise und Warnungen deutlich kennzeichnen: `Note:`, `Warning:`, `Important:`
-   Bedienelemente und Eingaben hervorheben, zum Beispiel fett: Click **Save**.

Ein typischer Aufbau einer README-Datei:

| Abschnitt          | Inhalt                                                      |
| ------------------ | ----------------------------------------------------------- |
| Project name       | Name und ein Satz, was das Projekt tut                      |
| Features           | wichtigste Funktionen                                       |
| Requirements       | Voraussetzungen (Betriebssystem, Laufzeitumgebung)          |
| Installation       | Schritte zur Installation                                   |
| Usage              | Beispiele zur Verwendung                                    |
| Configuration      | Einstellungen                                               |
| Contributing       | wie man mitarbeiten kann                                    |
| Licence            | Lizenz                                                      |

| Phrasen für Anleitungen                       |
| --------------------------------------------- |
| To install ..., follow these steps:           |
| Make sure that ... before you ...             |
| If ... appears, click ...                     |
| This will ...                                 |
| Once ... has finished, ...                    |
| Note that ...                                 |

## Berufliche E-Mails

Im Berufsleben ist der Ton meist **neutral bis formell**, aber kürzer und direkter als in einem Brief. Aufbau und Phrasen findest du unter [E-Mail](/de/languages/text_types/email/#formelle-e-mail). Für den Arbeitsalltag sind zusätzlich diese Wendungen nützlich:

| Situation             | Phrasen                                                                |
| --------------------- | ---------------------------------------------------------------------- |
| Bezug nehmen          | `Thank you for your email.` / `Following up on our call, ...`          |
| Anhang                | `Please find attached ...` / `I have attached ...`                     |
| Bitte                 | `Could you please ...?` / `I would be grateful if you could ...`       |
| Frist                 | `Could you send it by Friday?`                                         |
| Problem melden        | `I'm writing to report a problem with ...` / `When I try to ..., the following error appears: ...` |
| nachfassen            | `I'm just following up on my email from Monday.`                       |
| Schluss               | `Please let me know if you have any questions.` / `Best regards,`      |

:::tip[Fehlerbericht]
Ein guter Fehlerbericht (_bug report_) enthält: was du tun wolltest, was du getan hast (Schritte), was du erwartet hast (_expected behaviour_), was tatsächlich passiert ist (_actual behaviour_), die Fehlermeldung und Systeminformationen (Version, Betriebssystem).
:::

## Meetings

| Situation                  | Phrasen                                                                       |
| -------------------------- | ----------------------------------------------------------------------------- |
| eröffnen                   | `Let's get started.` / `The purpose of today's meeting is to ...`             |
| Tagesordnung               | `There are three items on the agenda.` / `Let's move on to the next point.`   |
| Meinung äußern             | `In my view, ...` / `I think we should ...`                                   |
| zustimmen                  | `I completely agree.` / `That's a good point.`                                |
| widersprechen (höflich)    | `I see your point, but ...` / `I'm not sure I agree.` / `Have we considered ...?` |
| unterbrechen               | `Sorry to interrupt, but ...` / `Could I just add something?`                 |
| nachfragen                 | `Could you clarify what you mean by ...?` / `So, if I understand you correctly, ...` |
| zusammenfassen             | `To sum up, we've agreed that ...`                                            |
| Aufgaben verteilen         | `Who will take care of ...?` / `Anna will ... by Friday.`                     |
| beenden                    | `Is there anything else?` / `Thanks, everyone. Let's meet again next week.`   |

Die Ergebnisse eines Meetings hält man in einem Protokoll (_minutes_) mit Aufgaben (_action items_), Verantwortlichen und Fristen fest.

| `_`     | underscore                                   |

`max.muster@htl.at` sagt man „max dot muster at h-t-l dot a-t“.

### Buchstabieralphabet

Beim Buchstabieren am Telefon verwendet man das internationale **NATO-Buchstabieralphabet**: Alfa, Bravo, Charlie, Delta, Echo, Foxtrot, Golf, Hotel, India, Juliett, Kilo, Lima, Mike, November, Oscar, Papa, Quebec, Romeo, Sierra, Tango, Uniform, Victor, Whiskey, X-ray, Yankee, Zulu. Beispiel: `M as in Mike`.
