Mündliches Englisch brauchst du in der HTL bei Referaten, bei der Präsentation der Diplomarbeit, in Praktika und bei der mündlichen Reife- und Diplomprüfung. Gefragt ist nicht fehlerfreies Englisch, sondern dass du zusammenhängend, verständlich und passend zur Situation sprichst und auf dein Gegenüber reagierst. Das Zielniveau am Ende der HTL ist **B2** des Gemeinsamen Europäischen Referenzrahmens.

## Die mündliche Prüfung

### Ablauf

Die mündliche Prüfung in einer lebenden Fremdsprache ist **kompetenzorientiert** und besteht aus zwei Teilen:

1.  **Themenbereiche:** Die Lehrkräfte legen für die Abschlussklasse einen Pool von Themenbereichen fest, die aus dem Lehrplan stammen (zum Beispiel _Technology and Society_, _Working Life_, _Environment_, _Media_). Die Liste wird rechtzeitig vor der Prüfung bekannt gegeben.
2.  **Ziehen:** Bei der Prüfung ziehst du zwei Themenbereiche und wählst einen davon. Zu diesem Themenbereich bekommst du eine Aufgabenstellung, die du vorher noch nicht kennst.
3.  **Vorbereitung:** Du bekommst eine Vorbereitungszeit, in der du dir Notizen machen darfst. Die Dauer der Vorbereitung und der Prüfung legt die Prüfungsordnung fest.
4.  **Prüfung:** Sie besteht aus einem **monologischen** und einem **dialogischen** Teil.

| Teil                    | Was du tust                                                                                     |
| ----------------------- | ----------------------------------------------------------------------------------------------- |
| **Monolog** (_long turn_) | ein zusammenhängender Beitrag zu einem Impuls: Situation, Leitfragen, oft Bilder, Grafiken oder ein kurzer Text. Du beschreibst, vergleichst, erklärst, begründest deine Meinung. |
| **Dialog** (_interaction_) | ein Gespräch mit der prüfenden Lehrkraft oder, bei der Paarprüfung, mit einer Mitschülerin oder einem Mitschüler: Rollenspiel, Diskussion, gemeinsam eine Entscheidung treffen, ein Problem lösen. |

Beurteilt wird, ob du die Aufgabe erfüllst, wie zusammenhängend und flüssig du sprichst, wie vielfältig und korrekt dein Wortschatz und deine Grammatik sind und wie gut du im Dialog auf dein Gegenüber eingehst.

:::note
Details wie Vorbereitungszeit, Prüfungsdauer und die Form des dialogischen Teils sind in der Prüfungsordnung für berufsbildende Schulen geregelt und können sich ändern. Die verbindliche Information bekommst du von deiner Schule und auf [matura.gv.at](https://www.matura.gv.at/).
:::

### Tipps für die Prüfung

-   **Lies die Aufgabe genau** und arbeite alle Punkte ab. Wer einen Punkt auslässt, verliert bei der Aufgabenerfüllung.
-   **Notizen statt ganzer Sätze:** Schreib Stichwörter und Linking Words auf, keine ausformulierten Texte zum Ablesen.
-   **Struktur zeigen:** Kündige an, was du sagen wirst, und verbinde die Punkte (`First, ... Then I'd like to ... Finally ...`).
-   **Begründen und Beispiele geben:** Eine Meinung ohne Begründung ist zu wenig für B2.
-   **Im Dialog reagieren:** Geh auf das Gesagte ein, frag nach, stimm zu oder widersprich begründet. Ein Dialog ist kein zweiter Monolog.
-   **Lücken überbrücken:** Wenn dir ein Wort fehlt, umschreib es (`It's a kind of ...`, `the thing you use to ...`) statt zu schweigen.

## Präsentationen

### Aufbau

| Teil                    | Inhalt                                                                         |
| ----------------------- | ------------------------------------------------------------------------------ |
| Begrüßung und Einstieg  | Begrüßung, Vorstellung, ein Einstieg, der Interesse weckt (Frage, Zahl, Bild)  |
| Überblick               | Thema und Gliederung (_signposting_)                                           |
| Hauptteil               | zwei bis vier Punkte, jeweils mit Überleitung                                  |
| Schluss                 | Zusammenfassung, Kernaussage, Dank                                             |
| Fragen                  | Fragen beantworten                                                             |

### Phrasen

| Einstieg                                                                  |
| ------------------------------------------------------------------------- |
| Good morning, everyone. Thank you for coming.                             |
| My name is ... and today I'm going to talk about ...                      |
| Have you ever wondered why ...?                                           |
| Did you know that ...?                                                    |

| Überblick und Überleitungen                                               |
| ------------------------------------------------------------------------- |
| My presentation is divided into three parts.                              |
| First, I'll ... Then I'll ... Finally, I'll ...                           |
| Let's start with ...                                                      |
| That brings me to my next point.                                          |
| Moving on to ...                                                          |
| As I mentioned earlier, ...                                               |

| Visuals                                                                   |
| ------------------------------------------------------------------------- |
| Let's have a look at this slide.                                          |
| As you can see on this chart, ...                                         |
| This diagram shows ...                                                    |
| I'd like to draw your attention to ...                                    |

| Schluss und Fragen                                                        |
| ------------------------------------------------------------------------- |
| To sum up, ... / In conclusion, ...                                       |
| The key point to remember is ...                                          |
| Thank you for your attention.                                             |
| Are there any questions?                                                  |
| That's a good question. / I'm afraid I don't know, but I'll find out.     |

:::tip[Folien]
Wenige Wörter pro Folie, große Schrift, ein Gedanke pro Folie. Lies nicht von den Folien ab; sie sollen dich unterstützen, nicht ersetzen.
:::

## Bilder beschreiben

| Bereich             | Phrasen                                                                         |
| ------------------- | ------------------------------------------------------------------------------- |
| Überblick           | `The picture shows ...` / `In this photo we can see ...`                        |
| Position            | `in the foreground / background`, `in the middle`, `on the left / right`, `in the top left-hand corner`, `next to`, `behind` |
| Personen, Handlung  | `A young woman is sitting at a desk.` (Present Progressive für Handlungen im Bild) |
| Vermutungen         | `She seems to be ...` / `He might be ...` / `It looks as if ...` / `It could be ...` / `They must be ...` |
| Vergleich           | `Both pictures show ...` / `While the first picture ..., the second ...` / `In contrast to ...` |
| Bezug zum Thema     | `This reminds me of ...` / `The picture illustrates the problem of ...`         |

Beschreib nicht nur, was du siehst, sondern deute es und stell einen Bezug zur Aufgabe her. Für Vermutungen sind [Modalverben der Deduktion](/de/languages/english/modal_verbs/#vermutungen-deduction) besonders nützlich.

Grafiken und Diagramme beschreibst du mit dem Wortschatz unter [Technical English](/de/languages/english/technical_english/#diagramme-beschreiben).

## Diskussionen

| Funktion                       | Phrasen                                                                     |
| ------------------------------ | --------------------------------------------------------------------------- |
| Meinung äußern                 | `In my opinion, ...` / `I strongly believe that ...` / `As far as I'm concerned, ...` |
| nach der Meinung fragen        | `What do you think?` / `How do you feel about ...?` / `Would you agree?`     |
| zustimmen                      | `I agree with you.` / `That's exactly what I think.` / `You have a point there.` |
| teilweise zustimmen            | `I agree up to a point, but ...` / `That may be true, but ...`               |
| widersprechen                  | `I'm afraid I disagree.` / `I see what you mean, but ...` / `I'm not so sure about that.` |
| Vorschlag machen               | `What about ...?` / `Why don't we ...?` / `How about ...?` / `Let's ...`     |
| auf einen Vorschlag reagieren  | `That's a good idea.` / `I'm not sure that would work because ...`           |
| Kompromiss finden              | `Maybe we could combine both ideas.` / `Shall we agree on ...?`              |
| nachfragen                     | `What do you mean by ...?` / `Could you give an example?`                   |
| Zeit gewinnen                  | `Well, let me think.` / `That's an interesting question.` / `How can I put it?` |
| zum Ergebnis kommen            | `So, we've decided to ...` / `So, we agree that ...`                         |
