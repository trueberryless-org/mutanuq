Fast jede Software, die heute entsteht, hat etwas mit dem Web zu tun: eine Website, eine Webanwendung im Browser oder eine Schnittstelle, über die Apps und Server Daten austauschen. Dieser Bereich erklärt die Technologien dahinter, vom Weg einer Anfrage durch das Netz über die drei Sprachen des Browsers (HTML, CSS, JavaScript) bis zu Frameworks, REST-APIs und Anwendungen am Server.

An der HTL für Informationstechnologie verteilen sich diese Inhalte auf mehrere Gegenstände: Webanwendungen und Schnittstellen in **Softwareentwicklung** (SEW) und in den **Informationstechnischen Projekten** (ITP), Gestaltung und Frontend-Entwicklung im Ausbildungsschwerpunkt **Medientechnik**. Die Serverbeispiele gibt es wie im Bereich [Softwareentwicklung](/de/software-development/) in **C#** (ASP.NET Core) und **Rust** (axum), die Beispiele für den Browser in HTML, CSS, JavaScript und TypeScript.
