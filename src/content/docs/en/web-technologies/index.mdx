Almost every piece of software created today has something to do with the Web: a website, a web application in the browser or an interface through which apps and servers exchange data. This section explains the technologies behind it, from the path of a request through the network and the three languages of the browser (HTML, CSS, JavaScript) to frameworks, REST APIs and applications on the server.

At the HTL for information technology, this content is spread across several subjects: web applications and interfaces in **software development** and in the **IT projects**, design and frontend development in the **media technology** specialisation. As in the [Software Development](/en/software-development/) section, the server examples are given in **C#** (ASP.NET Core) and **Rust** (axum), and the browser examples in HTML, CSS, JavaScript and TypeScript.
