Almost every application has to store data permanently, from the school's grade management to the web shop and the smartphone app. A **database management system** (DBMS) takes over this task: it stores data in a structured way, ensures its consistency, controls concurrent access by many users and protects the data in the event of system failures.

At the HTL, this material is taught in the subject **Information Systems**, complemented by projects in software development and IT projects. All SQL examples were run in PostgreSQL, all C# and Rust examples with .NET 10 and Rust (edition 2024).
