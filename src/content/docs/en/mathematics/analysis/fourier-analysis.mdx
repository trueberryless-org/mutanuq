**Fourier analysis** breaks a signal down into sine and cosine waves of different frequencies. It is one of the most important ideas in communications and media engineering: audio compression, equalisers, spectrum analysers, WLAN and mobile modulation (OFDM), image compression and the analysis of machine vibrations are all based on it. Instead of asking "what value does the signal have at each moment?" you ask "which frequencies does it contain, and how strongly?".

## Periodic functions

A function is called **periodic** with period $T$ if $f(t + T) = f(t)$ for all $t$. The **fundamental frequency** is $f_0 = \frac{1}{T}$, the **fundamental angular frequency** $\omega_0 = \frac{2\pi}{T}$.

The simplest periodic functions are the [harmonic oscillations](/en/mathematics/functions/trigonometric-functions/#the-general-sine-function) $A \sin(\omega t + \varphi)$. If you add oscillations whose frequencies are integer multiples of $f_0$ (**harmonics**, overtones), the result is again periodic with period $T$. The Fourier series reverses this: almost every periodic signal can be represented as such a sum.

## Fourier series

A periodic function $f$ with period $T$ is represented by its **Fourier series**:

$$
f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \big(a_n \cos(n \omega_0 t) + b_n \sin(n \omega_0 t)\big)
$$

Truncating after $N$ terms gives a **trigonometric polynomial** that approximates $f$. The more terms, the better the approximation.

### Fourier coefficients

The coefficients are calculated by integrating over one period:

$$
a_n = \frac{2}{T} \int_0^T f(t) \cos(n \omega_0 t)\,\mathrm{d}t \qquad b_n = \frac{2}{T} \int_0^T f(t) \sin(n \omega_0 t)\,\mathrm{d}t \qquad n = 0, 1, 2, \ldots
$$

The term $\frac{a_0}{2} = \frac{1}{T} \int_0^T f(t)\,\mathrm{d}t$ is the **DC component**, i.e. the [arithmetic mean](/en/mathematics/analysis/applications-of-integration/#arithmetic-mean) of the signal. Instead of $0$ to $T$, you can integrate over any interval of length $T$; often $[-\frac{T}{2}; \frac{T}{2}]$ is more convenient.

The formulas work because sine and cosine functions of different frequencies are **orthogonal**: the integral over one period of $\sin(n\omega_0 t) \cdot \sin(m\omega_0 t)$ is zero for $n \neq m$. If you multiply $f$ by $\sin(n\omega_0 t)$ and integrate, only the component of that one frequency remains.

### Using symmetry

| Symmetry of $f$ | Consequence |
| --------------- | ----------- |
| even: $f(-t) = f(t)$ | all $b_n = 0$, pure cosine series |
| odd: $f(-t) = -f(t)$ | all $a_n = 0$, pure sine series |
| half-wave symmetry: $f(t + \frac{T}{2}) = -f(t)$ | only odd $n$ occur |

This saves a lot of calculation. Shifting the signal in the $y$ direction changes only $a_0$; shifting it in the $t$ direction changes the phases but not the amplitudes.

### Amplitude-phase form

Combining sine and cosine of the same frequency gives

$$
f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} A_n \sin(n \omega_0 t + \varphi_n) \qquad A_n = \sqrt{a_n^2 + b_n^2}
$$

$A_n$ is the **amplitude** of the $n$-th harmonic. For the phase, $\tan\varphi_n = \frac{a_n}{b_n}$ (mind the quadrant).

## Example: Square wave

:::tip[Example]
The square wave with period $T = 2\pi$ (so $\omega_0 = 1$) is

$$
f(t) = \begin{cases} 1 & 0 < t < \pi \\ -1 & \pi < t < 2\pi \end{cases}
$$

It is odd, so $a_n = 0$. For $b_n$:

$$
b_n = \frac{2}{2\pi} \left( \int_0^{\pi} \sin(nt)\,\mathrm{d}t - \int_{\pi}^{2\pi} \sin(nt)\,\mathrm{d}t \right) = \frac{1}{\pi} \left( \frac{1 - \cos(n\pi)}{n} + \frac{1 - \cos(n\pi)}{n} \right) = \frac{2\big(1 - (-1)^n\big)}{n\pi}
$$

For even $n$, $b_n = 0$; for odd $n$, $b_n = \frac{4}{n\pi}$:

$$
f(t) = \frac{4}{\pi} \left( \sin t + \frac{\sin 3t}{3} + \frac{\sin 5t}{5} + \frac{\sin 7t}{7} + \ldots \right)
$$

The amplitudes of the harmonics decrease with $\frac{1}{n}$.
:::

The square wave contains only odd harmonics because it has half-wave symmetry. For a $10\ \text{MHz}$ square wave this means components at $10$, $30$, $50$, $70\ \text{MHz}$ and so on. A digital clock signal with steep edges therefore needs a bandwidth several times its fundamental frequency; a cable or low-pass filter that cuts off the harmonics rounds off the edges.

:::note[Gibbs phenomenon]
At the jumps, every finite partial sum overshoots the target value by about $9\,\%$ of the jump height. More terms make the overshoot narrower, but not lower. With the first three terms, for example, the value at $t = \frac{\pi}{2}$ is $\frac{4}{\pi}\left(1 - \frac{1}{3} + \frac{1}{5}\right) \approx 1.103$.
:::

## Example: Sawtooth wave

:::tip[Example]
The sawtooth wave $f(t) = t$ for $-\pi < t < \pi$, continued periodically with $T = 2\pi$, is odd, so $a_n = 0$. Using [integration by parts](/en/mathematics/analysis/integral-calculus/#integration-by-parts):

$$
b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} t \sin(nt)\,\mathrm{d}t = \frac{2}{\pi} \int_0^{\pi} t \sin(nt)\,\mathrm{d}t = \frac{2}{\pi} \left[ -\frac{t \cos(nt)}{n} + \frac{\sin(nt)}{n^2} \right]_0^{\pi} = -\frac{2\cos(n\pi)}{n} = \frac{2\,(-1)^{n+1}}{n}
$$

$$
f(t) = 2 \left( \sin t - \frac{\sin 2t}{2} + \frac{\sin 3t}{3} - \frac{\sin 4t}{4} + \ldots \right)
$$

Unlike the square wave, the sawtooth contains all harmonics, including the even ones.
:::

Sawtooth signals occur in the time base of oscilloscopes and in synthesisers; their rich sound is produced precisely by these harmonics.

## Spectrum

Plotting the amplitudes $A_n$ against the frequency $n f_0$ gives the **amplitude spectrum**. For periodic signals it is a **line spectrum**: there are lines only at multiples of the fundamental frequency.

| Signal | Spectrum |
| ------ | -------- |
| pure sine wave | a single line at $f_0$ |
| square wave | lines at $f_0, 3f_0, 5f_0, \ldots$ with heights $\frac{4}{\pi}, \frac{4}{3\pi}, \frac{4}{5\pi}, \ldots$ |
| sawtooth | lines at all $n f_0$ with heights $\frac{2}{n}$ |
| triangle | only odd harmonics, amplitudes fall with $\frac{1}{n^2}$ (faster, because the signal has no jumps) |

In general, the smoother a signal, the faster the amplitudes of its harmonics fall off. Jumps produce many high frequencies. The timbres of musical instruments differ in the strength of their overtones, even when they play the same note.

## Fourier transform

Using Euler's formula $e^{j\varphi} = \cos\varphi + j \sin\varphi$ (see [complex numbers](/en/mathematics/algebra/complex-numbers/#exponential-form)), the Fourier series can be written more compactly in **complex form**:

$$
f(t) = \sum_{n=-\infty}^{\infty} c_n \, e^{j n \omega_0 t} \qquad c_n = \frac{1}{T} \int_0^T f(t)\, e^{-j n \omega_0 t}\,\mathrm{d}t
$$

If the period $T$ tends to infinity, the spectral lines move closer and closer together. For **non-periodic** signals (a single pulse, a spoken word) you get a continuous spectrum, the **Fourier transform**:

$$
F(\omega) = \int_{-\infty}^{\infty} f(t)\, e^{-j \omega t}\,\mathrm{d}t
$$

$\lvert F(\omega) \rvert$ states how strongly the angular frequency $\omega$ is present in the signal. An important relationship: the shorter a pulse, the wider its spectrum. This is why high data rates (short symbols) need large bandwidths.

## Discrete Fourier transform (DFT)

In a computer, a signal is not available as a function but as a sequence of $N$ **samples** $x_0, x_1, \ldots, x_{N-1}$ measured at intervals of $\frac{1}{f_s}$ ($f_s$ is the sampling frequency). The **DFT** replaces the integral by a sum:

$$
X_k = \sum_{n=0}^{N-1} x_n \cdot e^{-j \frac{2\pi k n}{N}} \qquad k = 0, 1, \ldots, N - 1
$$

- $X_k$ is a complex number: its magnitude gives the strength and its argument the phase of the frequency $f_k = k \cdot \frac{f_s}{N}$.
- The **frequency resolution** is $\Delta f = \frac{f_s}{N}$: for finer resolution you have to measure for longer.
- For real signals, only $k = 0$ to $\frac{N}{2}$ are meaningful; the upper half is a mirror image. The amplitude of a sine component is $\frac{2\,\lvert X_k \rvert}{N}$ (for $0 < k < \frac{N}{2}$).

### FFT

The DFT by definition needs $N^2$ complex multiplications. The **fast Fourier transform** (FFT, Cooley-Tukey 1965) recursively splits the calculation into DFTs of half the size and needs only about $N \log_2 N$ operations. For $N = 1024$, that is around $10{,}000$ instead of a million operations. Only this made real-time signal processing practical; libraries such as FFTW and the DSP instructions in microcontrollers use the FFT.

<Tabs syncKey="code">
<TabItem label="C#">

```csharp
using System.Globalization;
using System.Numerics;

// DFT by definition (O(N²)); in practice you use an FFT library
static Complex[] Dft(double[] x)
{
    int n = x.Length;
    var result = new Complex[n];
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            result[k] += x[i] * Complex.Exp(new Complex(0, -2 * Math.PI * k * i / n));
    return result;
}

// 8 samples per second: 1 Hz sine with amplitude 1 plus 3 Hz sine with amplitude 0.5
const int N = 8;
double[] samples = new double[N];
for (int i = 0; i < N; i++)
    samples[i] = Math.Sin(2 * Math.PI * 1 * i / N) + 0.5 * Math.Sin(2 * Math.PI * 3 * i / N);

var spectrum = Dft(samples);
for (int k = 1; k < N / 2; k++)
    Console.WriteLine(string.Create(CultureInfo.InvariantCulture,
        $"{k} Hz: amplitude {2 * spectrum[k].Magnitude / N:F3}"));
// 1 Hz: amplitude 1.000
// 2 Hz: amplitude 0.000
// 3 Hz: amplitude 0.500
```

<TabItem label="Rust">

```rust
use std::f64::consts::PI;

/// DFT by definition (O(N²)); returns (real part, imaginary part) per frequency
fn dft(x: &[f64]) -> Vec<(f64, f64)> {
    let n = x.len() as f64;
    (0..x.len())
        .map(|k| {
            x.iter().enumerate().fold((0.0, 0.0), |(re, im), (i, &xi)| {
                let angle = -2.0 * PI * k as f64 * i as f64 / n;
                (re + xi * angle.cos(), im + xi * angle.sin())
            })
        })
        .collect()
}

fn main() {
    // 8 samples per second: 1 Hz sine with amplitude 1 plus 3 Hz sine with amplitude 0.5
    const N: usize = 8;
    let samples: Vec<f64> = (0..N)
        .map(|i| {
            let t = i as f64 / N as f64;
            (2.0 * PI * t).sin() + 0.5 * (2.0 * PI * 3.0 * t).sin()
        })
        .collect();

    let spectrum = dft(&samples);
    for (k, (re, im)) in spectrum.iter().enumerate().take(N / 2).skip(1) {
        let amplitude = 2.0 * re.hypot(*im) / N as f64;
        println!("{k} Hz: amplitude {amplitude:.3}");
    }
    // 1 Hz: amplitude 1.000
    // 2 Hz: amplitude 0.000
    // 3 Hz: amplitude 0.500
}
```

If a signal frequency does not fall exactly on an $f_k$, its energy spreads to neighbouring frequencies (**spectral leakage**). This is reduced by multiplying the signal by a **window function** (e.g. a Hann window) before the DFT, which brings it smoothly to zero at the edges.

### Applications

| Field | Application |
| ----- | ----------- |
| audio | spectrum display, equaliser, noise reduction, pitch detection; MP3 and AAC use the related modified discrete cosine transform (MDCT) |
| images | JPEG splits $8 \times 8$ pixel blocks with the discrete cosine transform (DCT) and stores high frequencies more coarsely |
| communications | OFDM in WLAN, LTE, 5G and DVB-T spreads data over many subcarriers; transmitter and receiver compute with the (inverse) FFT |
| measurement | spectrum analyser, harmonic analysis in the power grid, vibration analysis of machines |
| computing | fast convolution and multiplication of very large numbers via the FFT |

## Sampling theorem

For a signal to be reconstructed without error from its samples, the sampling frequency must be more than twice the highest frequency contained in the signal (**sampling theorem** after Nyquist and Shannon):

$$
f_s > 2 \cdot f_{\max}
$$

Half the sampling frequency, $\frac{f_s}{2}$, is called the **Nyquist frequency**. Frequencies above it are not simply dropped but appear as false, lower frequencies (**aliasing**): a $7\ \text{Hz}$ signal sampled at $f_s = 8\ \text{Hz}$ looks exactly like a $1\ \text{Hz}$ signal. This is why, before the [analogue-to-digital converter](/en/embedded-programming/analogue-digital-converter/), a low-pass filter (**anti-aliasing filter**) removes all frequencies above the Nyquist frequency.

:::tip[Example: Audio CD]
Human hearing reaches up to about $20\ \text{kHz}$. The audio CD samples at $44.1\ \text{kHz}$, so the Nyquist frequency is $22.05\ \text{kHz}$. The gap to $20\ \text{kHz}$ leaves room for a realisable anti-aliasing filter. Telephony with an $8\ \text{kHz}$ sampling rate, by contrast, only transmits frequencies up to just under $4\ \text{kHz}$, which is enough for speech intelligibility.
:::
