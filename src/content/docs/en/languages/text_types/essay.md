An essay is a structured, argumentative text on a question or a statement. It is written for a general, educated readership, such as your teacher or the readers of a school magazine, and aims to convince with clear arguments and examples. Unlike an [article](/en/languages/text_types/article/), its focus is not on entertaining the reader but on a clear, logically structured line of argument.

There are two forms:

| Form                                           | Aim                                                   | Where is your own opinion?           |
| ---------------------------------------------- | ----------------------------------------------------- | ------------------------------------ |
| **Opinion essay** (_argumentative essay_)      | take a position and convince the reader of it         | in the introduction and throughout   |
| **For-and-against essay** (_discursive essay_) | present arguments for and against in a balanced way   | only in the conclusion               |

:::note
The essay is a fixed text type of the SRDP English exam at AHS. At BHS it does not usually appear in the Matura, but it is practised in class because its argumentative structure reappears in articles, blog posts, letters to the editor and reports.
:::

## Characteristics

-   formal to neutral, no colloquial language and no short forms (`do not` instead of `don't`)
-   clear title, usually the question or topic of the task
-   each paragraph deals with **one** argument and starts with a **topic sentence**
-   arguments are supported by examples, facts or experience
-   **linking words** connect sentences and paragraphs logically
-   do not address the reader with `you`; for general statements use `people`, `many students` or `one`
-   in an opinion essay, use `I` only in the introduction and conclusion; in the main part prefer impersonal phrasing

## Layout

### Title

The title names the topic briefly. You often take the question from the task.

> Should smartphones be banned in schools?

### Introduction

The introduction catches the reader's interest (_hook_), for example with a figure, a question or a short situation, leads to the topic and ends with the **thesis statement**. In an opinion essay this is your opinion; in a for-and-against essay you announce that both sides will be considered.

> Nearly every teenager in Austria owns a smartphone, and many of them check it dozens of times a day. While some argue that phones distract pupils, I am convinced that a complete ban would do more harm than good.

### Main part

The main part usually consists of two to three paragraphs. Each paragraph follows the pattern **topic sentence, reason, example**.

-   **Opinion essay:** two paragraphs with arguments for your position, then one paragraph with a counter-argument that you refute (_counter-argument and refutation_).
-   **For-and-against essay:** one paragraph with arguments for, one with arguments against, both equally detailed.

> To begin with, smartphones are useful learning tools. Pupils can look up unknown words, check facts or use learning apps during lessons. In our IT classes, for example, we regularly use our phones to test responsive websites.

:::caution
One paragraph, one argument. If you put two arguments into one paragraph, the structure becomes unclear and you lose marks in the criterion _Organisation and Layout_.
:::

### Conclusion

The conclusion briefly sums up the main arguments without introducing new ones and states your opinion (for the first time in a for-and-against essay). An outlook or a recommendation rounds off the text.

> All things considered, the advantages of smartphones clearly outweigh the risks. Instead of banning them, schools should set clear rules for when phones may be used.

## Phrases

| Introduction                                              |
| --------------------------------------------------------- |
| These days, ... has become a hotly debated issue.         |
| It is often claimed that ...                              |
| Many people believe that ..., while others argue that ... |
| This essay will discuss whether ...                       |
| In my opinion, ... because ...                            |

| Introducing and adding arguments              |
| --------------------------------------------- |
| To begin with, ... / First of all, ...        |
| Furthermore, ... / Moreover, ...              |
| In addition to this, ...                      |
| Another argument in favour of ... is that ... |
| Not only ... but also ...                     |

| Examples and reasons                       |
| ------------------------------------------ |
| For example, ... / For instance, ...       |
| A good example of this is ...              |
| This is because ... / This is due to ...   |
| As a result, ... / Consequently, ...       |
| Studies have shown that ...                |

| Counter-arguments and refutation         |
| ---------------------------------------- |
| On the other hand, ...                   |
| Opponents of ... argue that ...          |
| Admittedly, ... However, ...             |
| Although it is true that ..., ...        |
| This argument does not hold, because ... |

| Conclusion                          |
| ----------------------------------- |
| In conclusion, ... / To sum up, ... |
| All things considered, ...          |
| On balance, I believe that ...      |
| Taking everything into account, ... |
| It is therefore advisable to ...    |

You will find more linking words and their punctuation under [Sentence Structure](/en/languages/english/sentence_structure/#linking-words-and-connectors).
