Prepositions can rarely be translated word for word: „am Montag“ is `on Monday`, „am Bahnhof“ is `at the station`, „im Internet“ is `on the internet`. Many prepositions are part of fixed combinations (_collocations_) and have to be learnt together with the word. **Phrasal verbs** are verbs with a particle (`set up`, `log in`) whose meaning often cannot be worked out from their parts.

## Prepositions of time

| Preposition | Use                                                              | Examples                                                    |
| ----------- | ---------------------------------------------------------------- | ----------------------------------------------------------- |
| `at`        | clock times, points in time, holidays as a period, the weekend (BrE) | `at 8 o'clock`, `at noon`, `at night`, `at Christmas`, `at the weekend` (AmE `on the weekend`), `at the moment` |
| `on`        | days, dates, a specific part of a day                            | `on Monday`, `on 5 May`, `on my birthday`, `on Friday evening` |
| `in`        | months, years, seasons, centuries, parts of the day, time until something happens | `in May`, `in 2024`, `in winter`, `in the 21st century`, `in the morning`, `in two weeks` (= two weeks from now) |

No preposition is used with `this`, `next`, `last`, `every`, `today`, `tomorrow`, `yesterday`: `I'll see you next Monday.` (not ~~on next Monday~~)

### Other prepositions of time

| Preposition                | Meaning                                          | Example                                               |
| -------------------------- | ------------------------------------------------ | ----------------------------------------------------- |
| `for`                      | duration                                         | `for three years`                                     |
| `since`                    | starting point                                   | `since 2020`                                          |
| `ago`                      | back from now (placed after)                     | `two days ago`                                        |
| `during`                   | in the course of (+ noun)                        | `during the meeting`                                  |
| `while`                    | in the course of (+ clause)                      | `while I was working`                                 |
| `by`                       | not later than                                   | `Please send it by Friday.`                           |
| `until`, `till`            | up to (continuing)                               | `I'll be in the office until 5 pm.`                   |
| `within`                   | inside a period                                  | `within 24 hours`                                     |
| `on time` / `in time`      | punctual / early enough                          | `The train was on time.` / `We arrived in time for the start.` |

:::caution[„bis“: by or until]
`by` means "at the latest" (an action is completed by then), `until` means "all the time up to" (a state continues): `Finish the report by Friday.` versus `I'll work on it until Friday.`
:::

## Prepositions of place

| Preposition | Use                                              | Examples                                                               |
| ----------- | ------------------------------------------------ | ---------------------------------------------------------------------- |
| `at`        | a point, a place as a meeting point or function  | `at the station`, `at the door`, `at the bus stop`, `at school`, `at work`, `at home`, `at the top`, `at a conference` |
| `in`        | inside a space or area                           | `in the room`, `in the box`, `in Vienna`, `in Austria`, `in the car`, `in a taxi`, `in the picture`, `in the photo` |
| `on`        | on a surface or line, public transport, media    | `on the desk`, `on the wall`, `on the first floor`, `on the bus`, `on the train`, `on the internet`, `on the website`, `on page 5`, `on the screen`, `on TV` |

### Movement and direction

| Preposition         | Meaning                       | Example                                        |
| ------------------- | ----------------------------- | ---------------------------------------------- |
| `to`                | towards a destination         | `go to Vienna`, `send it to me`                |
| `into` / `out of`   | entering / leaving            | `Plug the cable into the port.`                |
| `onto`              | moving onto a surface         | `Drag the file onto the desktop.`              |
| `through`           | from one side to the other inside | `The data passes through the firewall.`    |
| `across`            | from one side to the other    | `walk across the street`                       |
| `along`             | following a line              | `along the river`                              |
| `past`              | going by                      | `go past the school`                           |
| `towards`           | in the direction of           | `walk towards the exit`                        |

`arrive` takes `at` (building, place) or `in` (city, country), never `to`: `We arrived in London.`, `She arrived at the airport.` With `home` there is no preposition: `go home`, `arrive home`.

## Fixed combinations

### Verb + preposition

| Combination               | Example                                           |
| ------------------------- | ------------------------------------------------- |
| `agree with` sb / `on` sth | `I agree with you.` / `We agreed on a deadline.` |
| `apply for` (job) / `apply to` (company) | `I applied to Google for an internship.` |
| `ask for`                 | `ask for help`                                    |
| `consist of`              | `The team consists of five people.`               |
| `deal with`               | `deal with a problem`                             |
| `depend on`, `rely on`    | `It depends on the budget.`                       |
| `focus on`                | `focus on the main points`                        |
| `listen to`               | `listen to a podcast`                             |
| `pay for`                 | `pay for the licence`                             |
| `result in` / `result from` | `The bug resulted in data loss.`                |
| `succeed in`              | `succeed in fixing the bug`                       |
| `take part in`            | `take part in a competition`                      |
| `wait for`                | `wait for a response`                             |

No preposition is used with: `discuss` (not ~~discuss about~~), `enter` (not ~~enter into~~ a room), `call` (phone someone), `answer`, `reach`, `contact`, `lack`.

### Adjective + preposition

| Combination                        | Example                                             |
| ---------------------------------- | --------------------------------------------------- |
| `afraid of`, `aware of`, `capable of`, `proud of`, `tired of` | `I'm aware of the risk.`  |
| `good at`, `bad at`                | `She's good at maths.`                              |
| `interested in`                    | `interested in robotics`                            |
| `responsible for`                  | `responsible for the network`                       |
| `different from` (BrE also `to`)   | `Rust is different from C.`                         |
| `similar to`                       | `similar to Java`                                   |
| `angry with` sb / `about` sth      | `angry with my brother`                             |
| `keen on`                          | `keen on gaming`                                    |
| `based on`                         | `based on a survey`                                 |
| `familiar with`                    | `familiar with Linux`                               |

| ------------------------- | ----------------------------- |

| `by mistake`, `by accident` | unintentionally             |
| `by chance`               | by luck, unplanned            |
| `in advance`              | beforehand                    |
| `in my opinion`           | as I see it                   |
| `at least`, `at first`, `at last` | minimum, initially, finally |
| `out of order`            | not working                   |
| `on average`              | typically, as a mean          |
| `in charge of`            | responsible for               |
| `up to date`, `out of date` | current, outdated           |

## Phrasal verbs

A phrasal verb consists of a verb and one or two particles (`up`, `out`, `off`, `on`, `in`, `down`, `over`, ...). The meaning is often idiomatic: `give up` means "stop trying", `put off` means "postpone".

### Separable or inseparable

-   **separable**: a noun object can go before or after the particle, but a **pronoun must go in between**: `Turn off the computer.` = `Turn the computer off.` → `Turn it off.` (not ~~Turn off it.~~)
-   **inseparable**: the object always follows the particle: `I'll look after the kids.` → `I'll look after them.`
-   **three-part**: always inseparable: `I'm looking forward to it.`, `We ran out of memory.`

### Important phrasal verbs in everyday life and at work

| Phrasal verb        | Meaning                                  | Example                                           |
| ------------------- | ---------------------------------------- | ------------------------------------------------- |
| `bring up`          | mention (a topic)                        | `She brought up an interesting point.`            |
| `call off`          | cancel                                   | `The meeting was called off.`                     |
| `carry out`         | perform, conduct                         | `carry out a survey`                              |
| `come up with`      | think of (an idea)                       | `come up with a solution`                         |
| `deal with`         | handle                                   | `deal with complaints`                            |
| `figure out`        | understand, solve                        | `I can't figure out the error.`                   |
| `fill in` / `fill out` | complete (a form)                     | `fill in the form`                                |
| `find out`          | discover                                 | `find out the cause`                              |
| `get along with`    | have a good relationship with            | `I get along with my colleagues.`                 |
| `give up`           | stop trying                              | `Don't give up.`                                  |
| `go on`             | continue, happen                         | `What's going on?`                                |
| `look after`        | take care of                             | `look after the servers`                          |
| `look into`         | investigate                              | `We'll look into the problem.`                    |
| `look up`           | search for information                   | `look up a word`                                  |
| `point out`         | draw attention to                        | `point out a mistake`                             |
| `put off`           | postpone                                 | `Don't put it off.`                               |
| `put up with`       | tolerate                                 | `put up with slow Wi-Fi`                          |
| `run out of`        | have none left                           | `We ran out of disk space.`                       |
| `set up`            | establish, configure                     | `set up a company`, `set up a router`             |
| `sort out`          | resolve                                  | `sort out a problem`                              |
| `take over`         | take control of                          | `take over a project`                             |
| `turn down`         | refuse; reduce volume                    | `turn down an offer`                              |

### Phrasal verbs in IT

| Phrasal verb               | Meaning                                       | Example                                              |
| -------------------------- | --------------------------------------------- | ---------------------------------------------------- |
| `back up`                  | make a copy for safety                        | `Back up your files regularly.`                      |
| `boot up`, `start up`      | start a computer                              | `The PC takes ages to boot up.`                      |
| `shut down`                | turn off properly                             | `Shut down the server before maintenance.`           |
| `log in`, `log on`         | sign in to a system                           | `Log in with your school account.`                   |
| `log out`, `log off`       | sign out of a system                          | `Don't forget to log out.`                           |
| `sign up`                  | register                                      | `sign up for a free account`                         |
| `plug in`                  | connect to power or a port                    | `Plug in the charger.`                               |
| `set up`                   | install and configure                         | `set up a VPN`                                       |
| `roll out`                 | introduce gradually                           | `roll out an update`                                 |
| `roll back`                | return to an earlier version                  | `roll back to the previous version`                  |
| `scale up` / `scale out`   | add resources to one machine / add machines   | `scale out the web servers`                          |
| `free up`                  | make available                                | `free up disk space`                                 |
| `clean up`                 | tidy, remove what is not needed               | `clean up the code`                                  |
| `print out`                | print on paper                                | `print out the invoice`                              |
| `zoom in` / `zoom out`     | enlarge / reduce the view                     | `Zoom in on the chart.`                              |
| `scroll down` / `scroll up` | move the view down / up                      | `Scroll down to the bottom.`                         |
| `key in`, `type in`        | enter with the keyboard                       | `Type in your password.`                             |
| `break down`               | stop working; divide into parts               | `The system broke down.`, `break down the costs`     |
| `time out`                 | stop because a time limit was reached         | `The connection timed out.`                          |
| `opt in` / `opt out`       | choose to take part / not to take part        | `opt out of tracking`                                |
| `phase out`                | gradually stop using                          | `phase out Windows 10`                               |
| `lock out`                 | prevent from getting in                       | `I locked myself out of my account.`                 |

:::tip[Verb or noun]
Many IT terms are two words as a verb but one word as a noun or adjective: `to log in` / `the login page`, `to back up` / `a backup`, `to set up` / `the setup`, `to shut down` / `a shutdown`, `to start up` / `a startup`, `to sign up` / `a signup form`. So it is `Please log in.`, but `Enter your login details.`
:::
