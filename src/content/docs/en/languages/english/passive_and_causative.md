In the active voice the doer of the action is in focus (`The admin installs the update.`); in the passive voice the action or the thing affected by it is in focus (`The update is installed.`). Use the passive when the doer is unknown, unimportant or obvious, and in factual texts such as [reports](/en/languages/text_types/report/), minutes and technical descriptions.

## Form

The passive is formed with a form of **`be`** + **past participle** (3rd form). The tense is always carried by `be`; the participle stays the same. The object of the active sentence becomes the subject of the passive sentence.

| Tense                      | Active                                 | Passive                                    |
| -------------------------- | -------------------------------------- | ------------------------------------------ |
| Present simple             | They **test** the code.                | The code **is tested**.                    |
| Present progressive        | They **are testing** the code.         | The code **is being tested**.              |
| Present perfect            | They **have tested** the code.         | The code **has been tested**.              |
| Past simple                | They **tested** the code.              | The code **was tested**.                   |
| Past progressive           | They **were testing** the code.        | The code **was being tested**.             |
| Past perfect               | They **had tested** the code.          | The code **had been tested**.              |
| Future simple              | They **will test** the code.           | The code **will be tested**.               |
| Future perfect             | They **will have tested** the code.    | The code **will have been tested**.        |
| going to                   | They **are going to test** the code.   | The code **is going to be tested**.        |
| Modal verb                 | They **must test** the code.           | The code **must be tested**.               |
| Modal perfect              | They **should have tested** the code.  | The code **should have been tested**.      |
| Infinitive                 | I want them **to test** it.            | I want it **to be tested**.                |
| Gerund                     | I don't like people **criticising** me. | I don't like **being criticised**.        |

The perfect progressive forms and the future progressive (`will be being tested`) are grammatically possible in the passive but sound clumsy and are hardly ever used.

Negatives and questions are formed with the first auxiliary: `The code wasn't tested.`, `Has the code been tested?`

:::caution
Only verbs with an object (transitive verbs) have a passive. `happen`, `arrive`, `die`, `occur` have none: ~~The accident was happened.~~ Correct: `The accident happened.`
:::

## The by-agent

The doer (_agent_) is added with `by`, but only if it is important or new information.

-   `The World Wide Web was invented by Tim Berners-Lee.` (The information matters.)
-   `My bike was stolen.` (Thief unknown, no `by someone`.)
-   `The suspect was arrested.` (Obviously by the police, no `by the police`.)

An instrument or tool is added with `with`: `The file was encrypted with AES.`

## Passive with two objects

Verbs such as `give`, `send`, `show`, `offer`, `tell`, `teach`, `lend`, `pay` have an indirect object (person) and a direct object (thing). Either can become the subject of the passive sentence.

| Active                                      | Passive with the person as subject (more common) | Passive with the thing as subject              |
| ------------------------------------------- | ------------------------------------------------ | ----------------------------------------------- |
| They gave **me** **a new laptop**.          | **I** was given a new laptop.                    | **A new laptop** was given to me.               |
| The company offered **her** **a job**.      | **She** was offered a job.                       | **A job** was offered to her.                   |

The passive with the person as subject is more usual in English and has no direct German equivalent („Mir wurde ein Laptop gegeben.“).

## Passive with prepositional verbs

With verbs that take a preposition, the preposition stays after the participle.

-   `Somebody must deal with the problem.` becomes `The problem must be dealt with.`
-   `Everybody laughed at him.` becomes `He was laughed at.`
-   `They looked after the servers well.` becomes `The servers were looked after well.`

## Impersonal passive

With verbs of saying and believing (`say`, `believe`, `think`, `know`, `report`, `expect`, `consider`, `claim`, `estimate`) you report general opinions or reports without naming a source. This is typical of news, reports and essays. There are two constructions:

| Active                                     | `It is said that ...`                          | Personal construction                            |
| ------------------------------------------ | ---------------------------------------------- | ------------------------------------------------ |
| People say that he is a genius.            | It is said that he is a genius.                | He **is said to be** a genius.                   |
| People believe that the hacker lives in Asia. | It is believed that the hacker lives in Asia. | The hacker **is believed to live** in Asia.     |
| Experts think the attack started last week. | It is thought that the attack started last week. | The attack **is thought to have started** last week. |
| They report that the CEO is negotiating.   | It is reported that the CEO is negotiating.    | The CEO **is reported to be negotiating**.       |

In the personal construction the infinitive depends on the time of the reported clause:

-   same time: `to be`, `to do` (`He is said to be rich.`)
-   same time, in progress: `to be doing` (`She is believed to be working on a new app.`)
-   earlier time: `to have done` (`He is said to have earned millions.`)

With `there` there is a special form: `There are said to be more than 8 billion people on Earth.`

## Causative: have/get something done

With the **causative** you express that you **have something done** for you, i.e. you do not do it yourself but arrange for someone else to do it.

**Form:** `have` or `get` + object + past participle. `have` is slightly more formal, `get` more informal. The tense is carried by `have/get`.

| Sentence                                               | Meaning                                                     |
| ------------------------------------------------------ | ----------------------------------------------------------- |
| `I repaired my laptop.`                                | I repaired it myself.                                       |
| `I had my laptop repaired.`                            | Someone repaired it for me.                                 |
| `We are having the network upgraded next week.`        | A company will upgrade our network next week.               |
| `You should get your eyes tested.`                     | You should go to an optician.                               |
| `She has just had her hair cut.`                       | A hairdresser has just cut her hair.                        |

`have something done` also describes **unpleasant experiences** that happened to you: `I had my phone stolen on the train.` (Somebody stole my phone.)

### Other causative structures

| Structure                                     | Example                                                   |
| --------------------------------------------- | --------------------------------------------------------- |
| `have` + person + base form                   | `I'll have the technician check the printer.`            |
| `get` + person + `to` + base form             | `I got my brother to install the software.`              |
| `make` + person + base form (force)           | `The teacher made us rewrite the essay.`                 |
| `let` + person + base form (allow)            | `My parents let me use their car.`                       |

In the passive, `make` takes `to`: `We were made to rewrite the essay.`

## Passive in technical texts

Descriptions of processes and systems use the passive in the present simple, because the device or the data matter more than the person.

> When a user logs in, the password is hashed and compared with the stored hash. If the values match, a session token is created and sent to the browser.

Do not overuse the passive, though: instructions are written in the imperative (`Click Save.`), and in emails the active voice sounds more personal.
