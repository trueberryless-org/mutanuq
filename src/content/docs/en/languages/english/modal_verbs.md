Modal verbs (_modal auxiliaries_) change the meaning of a main verb: they express ability, permission, obligation, advice or probability. They cause many mistakes for German speakers, because some look like German words but are used differently (`must not` does not mean "not have to").

## Grammatical features

The true modal verbs (`can`, `could`, `may`, `might`, `must`, `shall`, `should`, `will`, `would`, `ought to`) follow special rules:

-   no `-s` in the 3rd person: `She can code.` (not ~~cans~~)
-   no `do` in questions and negatives: `Can you help?`, `You mustn't go.`
-   followed by the base form without `to`: `You should go.` (exception: `ought to`)
-   no infinitive, `-ing` or participle form; other tenses need **substitute forms**

| Modal verb | Substitute form          | Example                                         |
| ---------- | ------------------------ | ----------------------------------------------- |
| `can`      | `be able to`             | `I will be able to come tomorrow.`              |
| `must`     | `have to`                | `I had to work late yesterday.`                 |
| `may` (permission) | `be allowed to`  | `We have been allowed to use the lab.`          |

## Ability: can, could, be able to

-   `can`: ability in the present: `I can speak three languages.`
-   `could`: general ability in the past: `I could read when I was four.`
-   `was/were able to` or `managed to`: a **single**, successfully completed action in the past: `The fire spread quickly, but everyone was able to escape.` (not ~~could escape~~)
-   in the negative, `couldn't` is possible in both cases: `I couldn't open the file.`

## Permission: can, could, may, be allowed to

| Form                       | Use                                | Example                                  |
| -------------------------- | ---------------------------------- | ---------------------------------------- |
| `Can I ...?`               | informal                           | `Can I borrow your charger?`             |
| `Could I ...?`             | polite                             | `Could I ask you a question?`            |
| `May I ...?`               | formal, very polite                | `May I come in?`                         |
| `be allowed to`            | permission by a rule, all tenses   | `We weren't allowed to use phones.`      |

## Obligation and prohibition: must, have to, mustn't, don't have to

| Form              | Meaning                                                         | Example                                           |
| ----------------- | --------------------------------------------------------------- | ------------------------------------------------- |
| `must`            | obligation from the speaker's point of view, written rules      | `I must call my grandma.` / `Passengers must wear seat belts.` |
| `have to`         | external obligation (rules, circumstances)                      | `I have to wear a uniform at work.`              |
| `mustn't`         | **prohibition**: you are not allowed to                         | `You mustn't share your password.`                |
| `don't have to`   | **no necessity**: it is not necessary                           | `You don't have to come, it's optional.`          |
| `needn't`, `don't need to` | no necessity                                           | `You needn't print the document.`                 |

:::danger[False friend: must not]
If something is not necessary, say `You don't have to come.` or `You needn't come.`, **not** ~~You mustn't come.~~ (that would mean that you are not allowed to come).
:::

`must` has no past form. For past obligation use `had to`: `Yesterday I had to restart the server three times.`

## Advice: should, ought to, had better

-   `should` and `ought to`: advice, recommendation, expectation; `ought to` is less common and slightly more formal: `You should back up your data regularly.`
-   `had better` (`'d better`) + base form: urgent advice with a warning, about a specific situation: `You'd better leave now, or you'll miss the bus.` Negative: `You'd better not ...`

## Other uses

| Modal verb     | Use                                       | Example                                            |
| -------------- | ----------------------------------------- | -------------------------------------------------- |
| `shall`        | offer, suggestion in questions with I/we  | `Shall I open the window?` / `Shall we start?`     |
| `will`         | willingness, request                      | `Will you help me?`                                |
| `would`        | polite request, wish                      | `Would you mind closing the door?` / `I would like a coffee.` |
| `would`        | past habit (actions)                      | `As a child, I would play outside for hours.`      |
| `used to`      | past habit or past state                  | `I used to live in Graz.`                          |
| `need`         | necessity (as a main verb with `to`)      | `Do I need to register?`                           |

`would` for past habits only works with actions, not with states: ~~I would live in Graz.~~ Only `used to` is possible here.

## Deduction

Modal verbs express how certain you are about a conclusion.

| Certainty                           | Present                         | Past                                       |
| ----------------------------------- | ------------------------------- | ------------------------------------------ |
| almost certain it is true           | `must`                          | `must have` + participle                   |
| possible                            | `may`, `might`, `could`         | `may/might/could have` + participle        |
| almost certain it is not true       | `can't`, `couldn't`             | `can't/couldn't have` + participle         |

-   `The lights are off. They must be asleep.`
-   `He isn't answering. He might be in a meeting.`
-   `That can't be Anna, she's in London.`
-   `The server must have crashed during the night.`
-   `She can't have seen the email; she hasn't replied.`

:::caution
The opposite of `must` (deduction) is `can't`, not `mustn't`: ~~He mustn't be at home.~~ Correct: `He can't be at home.`
:::

## Modal perfect

Modal verb + `have` + past participle refers to the past, usually to something that did not happen or happened differently.

| Form                      | Meaning                                             | Example                                                      |
| ------------------------- | --------------------------------------------------- | ------------------------------------------------------------ |
| `should have done`        | would have been right but was not done (criticism, regret) | `You should have tested the code before deploying it.` |
| `shouldn't have done`     | was done but was wrong                              | `I shouldn't have clicked that link.`                        |
| `could have done`         | would have been possible but did not happen         | `You could have asked me for help.`                          |
| `would have done`         | would have happened under different circumstances   | `I would have come, but I was ill.`                          |
| `needn't have done`       | was done but was unnecessary                        | `You needn't have printed it; I had a copy.`                 |
| `didn't need to do`       | was unnecessary (and usually not done)              | `I didn't need to print it, so I didn't.`                    |
