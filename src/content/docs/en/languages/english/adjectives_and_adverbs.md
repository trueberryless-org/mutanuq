**Adjectives** describe nouns (`a fast computer`); **adverbs** describe verbs, adjectives, other adverbs or whole sentences (`It runs fast.`, `extremely fast`, `Fortunately, ...`). In German, adjective and adverb often look the same („Er fährt schnell.“); in English they usually do not: `He is a careful driver.` versus `He drives carefully.`

## Forming adverbs

Most adverbs are formed from adjective + `-ly`.

| Rule                          | Examples                                               |
| ----------------------------- | ------------------------------------------------------ |
| adjective + `-ly`             | `quick` → `quickly`, `careful` → `carefully`, `nice` → `nicely` |
| consonant + `-y` → `-ily`     | `easy` → `easily`, `happy` → `happily`                 |
| `-le` → `-ly`                 | `simple` → `simply`, `possible` → `possibly`, `gentle` → `gently` |
| `-ic` → `-ically`             | `basic` → `basically`, `automatic` → `automatically` (exception: `public` → `publicly`) |
| `-ll` → `-lly`                | `full` → `fully`                                       |
| `-ue` → `-uly`                | `true` → `truly`                                       |

### Irregular adverbs

| Adjective | Adverb  | Note                                                                       |
| --------- | ------- | -------------------------------------------------------------------------- |
| `good`    | `well`  | `She is a good programmer. She codes well.`                                |
| `fast`    | `fast`  | ~~fastly~~ does not exist                                                  |
| `hard`    | `hard`  | `He works hard.`; `hardly` means "almost not"                              |
| `late`    | `late`  | `She arrived late.`; `lately` means "recently"                             |
| `early`   | `early` | `I got up early.`                                                          |
| `straight`, `daily`, `monthly` | same | `Go straight on.`, `a daily backup`, `backed up daily`              |

`well` is also an adjective meaning "healthy": `I'm not feeling well.`

### Adjectives ending in -ly

`friendly`, `lovely`, `lonely`, `silly`, `likely`, `ugly`, `costly` are **adjectives** and have no adverb form. Use a paraphrase: `She smiled in a friendly way.`

### Adjectives after linking verbs

After verbs that describe a state or a sense impression, use the **adjective**, because it describes the subject, not the action: `be`, `become`, `get`, `seem`, `appear`, `look`, `sound`, `feel`, `smell`, `taste`, `stay`, `remain`.

-   `That sounds good.` (not ~~sounds well~~)
-   `I feel bad about it.`
-   `She looks tired.` versus `She looked carefully at the code.` (here `look` describes an action)

### -ed and -ing adjectives

-   `-ed` describes how someone **feels**: `I'm bored.`, `She is interested in AI.`
-   `-ing` describes what **causes** the feeling: `The lesson is boring.`, `AI is interesting.`

`I am boring.` means that other people find you dull, not that you feel bored.

## Comparison

| Adjective                              | Comparative                   | Superlative                       |
| -------------------------------------- | ----------------------------- | --------------------------------- |
| one syllable                           | `fast` → `faster`             | `the fastest`                     |
| one syllable ending in `-e`            | `large` → `larger`            | `the largest`                     |
| one syllable, short vowel + consonant  | `big` → `bigger`, `hot` → `hotter` | `the biggest`                |
| two syllables ending in `-y`           | `easy` → `easier`, `happy` → `happier` | `the easiest`            |
| two or more syllables                  | `modern` → `more modern`, `expensive` → `more expensive` | `the most expensive` |
| adverbs ending in `-ly`                | `quickly` → `more quickly`    | `the most quickly`                |

Some two-syllable adjectives have both forms: `clever`, `narrow`, `quiet`, `simple`, `polite` (`simpler` or `more simple`).

### Irregular comparison

| Base form           | Comparative            | Superlative                   |
| ------------------- | ---------------------- | ----------------------------- |
| `good` / `well`     | `better`               | `the best`                    |
| `bad` / `badly`     | `worse`                | `the worst`                   |
| `much` / `many`     | `more`                 | `the most`                    |
| `little`            | `less`                 | `the least`                   |
| `far`               | `farther` / `further`  | `the farthest` / `the furthest` |
| `old`               | `older` / `elder`      | `the oldest` / `the eldest`   |

`further` also means "additional": `further information`. `elder`/`eldest` are only used for family members before a noun: `my elder sister`.

### Comparative structures

| Structure                                 | Example                                                        |
| ----------------------------------------- | -------------------------------------------------------------- |
| comparative + `than`                      | `SSDs are faster than HDDs.`                                   |
| `as ... as` (equal)                       | `This laptop is as fast as mine.`                              |
| `not as/so ... as` (less)                 | `Java is not as concise as Python.`                            |
| `the` + comparative, `the` + comparative  | `The more you practise, the better you get.`                   |
| comparative + `and` + comparative         | `Computers are getting faster and faster.`                     |
| intensifying                              | `much/far/a lot faster`, `slightly/a bit faster`               |
| superlative + `in` (place, group as a unit) | `the best student in the class`                              |
| superlative + `of` (plural)               | `the fastest of all the models`                                |

After `than` and `as`, neutral English uses the object pronoun (`She is taller than me.`); formal English uses subject + verb (`She is taller than I am.`).

:::caution
~~more better~~, ~~more faster~~ and ~~the most best~~ are wrong: compare only once. German „als“ in comparisons is `than`, not ~~then~~ or ~~as~~.
:::

## Order of adjectives

When several adjectives come before a noun, they usually follow this order (opinion before facts):

| 1 opinion | 2 size  | 3 age   | 4 shape | 5 colour | 6 origin  | 7 material | 8 purpose/type | noun |
| --------- | ------- | ------- | ------- | -------- | --------- | ---------- | -------------- | ---- |
| `nice`    | `small` | `old`   | `round` | `black`  | `Italian` | `leather`  | `office`       | chair |

-   `a beautiful old wooden house`
-   `a powerful new gaming laptop`
-   `a small black USB cable`

In practice, rarely more than three adjectives come before a noun. Adjectives from different groups are not separated by commas; adjectives from the same group are separated by a comma or `and`: `a cheap, reliable laptop`.

## Adverb position

Adverbs can go at the beginning (_front position_), in the middle (_mid position_) or at the end of a sentence (_end position_).

| Type                        | Position                                                    | Example                                                    |
| --------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| frequency (`always`, `usually`, `often`, `never`) | mid: before the main verb, after `be` and after the first auxiliary | `I usually start at 8.` / `She is always late.` / `I have never seen it.` |
| manner (`carefully`, `quickly`) | usually at the end, after the object                    | `He checked the code carefully.`                           |
| place (`here`, `at home`)   | end                                                         | `I'll wait here.`                                          |
| time (`yesterday`, `soon`)  | end or front                                                | `I'll call you tomorrow.` / `Tomorrow I'll call you.`      |
| sentence adverbs (`fortunately`, `obviously`, `however`) | usually front with a comma     | `Fortunately, nobody was hurt.`                            |
| degree (`very`, `extremely`, `quite`) | before the adjective or adverb                    | `extremely fast`                                           |
| focus (`only`, `even`, `also`, `just`) | mid or before the stressed word                  | `I only need five minutes.`                                |

No adverb goes between the verb and the object: ~~She speaks very well English.~~ Correct: `She speaks English very well.`

## Confusing pairs

| Word pair                        | Meaning and example                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| `hard` / `hardly`                | with effort / almost not: `I work hard.`, `I can hardly hear you.`                   |
| `late` / `lately`                | not on time / recently: `Have you seen him lately?`                                  |
| `near` / `nearly`                | close / almost: `I nearly missed the bus.`                                           |
| `high` / `highly`                | at a great height / very: `The plane flew high.`, `highly recommended`               |
| `most` / `mostly`                | the majority of / mainly: `Most users are students.`, `The users are mostly students.` |
| `short` / `shortly`              | not long / soon: `I'll be there shortly.`                                            |
| `quite` / `quiet`                | fairly / not loud                                                                    |
| `so` / `such`                    | `so` + adjective, `such (a)` + (adjective +) noun: `so fast`, `such a fast laptop`   |
| `too` / `enough`                 | `too` before the adjective, `enough` after it (but before nouns): `too slow`, `fast enough`, `enough memory` |
| `economic` / `economical`        | related to the economy / saving money                                                |
| `historic` / `historical`        | important in history / related to history                                            |
| `electric` / `electrical` / `electronic` | powered by electricity / related to electricity / using electronics      |
| `sensible` / `sensitive`         | reasonable / easily affected, delicate                                               |
| `fun` / `funny`                  | enjoyable / amusing or strange                                                       |
