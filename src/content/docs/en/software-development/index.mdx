Software development is the core subject of information technology at the HTL and accompanies the entire course from the first to the fifth year. In this section, you will learn how to build programs that do not just run but stay **understandable**, extensible and maintainable, even when many people work on them over several years.

All code examples are available in **C#** and **Rust**. C# is the language taught at the HTL Krems; Rust shows a modern, systems-level approach without a garbage collector. Use the tabs above each example to choose the language. Your choice is remembered on all pages. Every example has been compiled and run with .NET 10 and Rust (edition 2024).
