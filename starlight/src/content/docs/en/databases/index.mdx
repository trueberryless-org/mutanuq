Almost every application has to store data permanently – from the school's grade management to web shops and smartphone apps. A **database management system** (DBMS) takes care of this task: it stores data in a structured way, ensures its consistency, controls simultaneous access by many users and protects the data in the event of system failures.

## What to expect

- **Relational databases:** Tables, keys, JOINs, ACID transactions and normal forms.
- **Document-oriented databases:** NoSQL databases such as MongoDB and CouchDB and the BASE model.
- **Database schema:** How the structure and integrity constraints of a database are defined.
- **CAP theorem:** Which trade-offs distributed database systems have to make.
