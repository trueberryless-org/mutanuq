Special function registers (SFR) are special memory locations through which the hardware of the microcontroller is controlled. There are some important registers used for the input and output of data. Since C is case-sensitive, the names must be written exactly as they are defined: the names of the `SFR` are always written in `UPPERCASE`. In addition, these registers are always eight bits wide, i.e. `1 byte`. By default, all `DDRx` and `PORTx` registers are initialised with `0`.

## Examples

### Setting input / output

This is how to configure pin `1` of port `D` as an output:

```c
DDRD |= (1<<PORTD1);
```

This is how to configure pin `1` of port `D` as an input (default):

```c
DDRD &= ~(1<<PORTD1);
```

### Applying a voltage to a pin

This is how to apply a voltage of `5V` to pin `1` of port `D`:

```c
PORTD |= (1<<PORTD1);
```

This is how to apply no voltage to pin `1` of port `D` (default):

```c
PORTD &= ~(1<<PORTD1);
```

### Reading the voltage of a pin

This is how to read the voltage of pin `1`, port `D`:

```c
if (PIND & (1<<PIND1))
{
    // Pin is high (on the ATmega328P with a 5V supply from about 3V)
}
```

When reading button inputs, the [method with the internal pull-up resistor](/en/embedded-programming/button/#internal-pull-up-resistor) is usually used. Here, 0V is applied when the button is pressed, which means that the condition must be negated. To debounce the button (at software level), a delay is added.

```c del="!"
if (!(PIND & (1<<PIND1)))
{
    // Button (pull-up) is pressed
}

// Avoid bouncing
_delay_ms(70);
```
