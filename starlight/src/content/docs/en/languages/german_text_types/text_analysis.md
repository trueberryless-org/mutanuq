The text analysis is a factual, analytical text type that analyses the source text according to many criteria. Because of these criteria, the text analysis always follows the same scheme, which you only have to learn by heart. The text analysis is written in the present tense and the present perfect.

## Characteristics

A text analysis has the following characteristics:

-   do not use `Ich` (I)
-   standard introduction with title, author, text type, place and date of publication of the source text
-   do not interpret, only quote (direct quotes)
-   be able to recognise [stylistic devices](/en/languages/german_text_types/stylistic_devices/)
-   use technical terms (if the topic is `IT`, you can include such technical vocabulary)
-   factual wording
-   write at most 50 words more than required
-   no heading
-   medium-length to long text type

## Structure

### Introduction

In the introduction of a text analysis, you only briefly mention the author, the title, the place and date of publication and the type (report, gloss, commentary, column, ...) of the source text. You can use a basic introduction for this:

> Die Glosse „Online einkaufen war gestern - heute gehen wir Echtzeitshoppen“ von Sybille Hamann aus „der Presse“ beschäftigt sich auf satirische Weise mit dem Thema Onlineshopping und dem damit verbundenen Riesenaufwand.

### Main part

The main part summarises the content of the source text in two to three sentences and then moves directly on to the **formal** (structure and organisation), **linguistic** (language, sentence structures, style, rhetorical devices, choice of words) and **content-related** (content, argumentation, intention) analysis. The following table shows which features must always be analysed:

| Criterion                                    | Possible results |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Content                                      | reproduce the content of the source text in your own words in about 75 words |
| Sections / structure                         | list the sections that are separated by content, using line numbers |
| Sentence structures (+ examples)             | <ul style="margin-top: 1rem"><li><p><strong>paratactic</strong><br>mostly main clauses (parataxis)</p></li><li><p><strong>hypotactic</strong><br>many subordinate clauses and complex sentences (hypotaxis); many commas</p></li></ul> |
| Language + examples                          | standard language, educated language, colloquial language, youth language |
| Argumentation + examples                     | <ul style="margin-top: 1rem"><li><p><strong>factual arguments</strong><br>justification by scientific facts</p></li><li><p><strong>value arguments</strong> / normative arguments<br>justification by social <em>norms / values / rules</em></p></li><li><p><strong>comparative arguments</strong> / arguments by analogy<br>comprehensibility through comparison with another field</p></li><li><p><strong>arguments from authority</strong><br>justification by statements of experts or recognised organisations</p></li><li><p><strong>indirect arguments</strong><br>refutation of alternative positions</p></li><li><p><strong>plausibility argument</strong><br>logical conclusions</p></li></ul> |
| Word fields / vocabulary                     | does the author use the technical terms of the topic? |
| Parts of speech + examples                   | many nouns (nominal style), verbs, adjectives |
| [Stylistic devices](/en/languages/german_text_types/stylistic_devices/) + many examples | Which stylistic devices are used? Always name the type of rhetorical device with as many examples as possible. You can also list which stylistic devices are not used in the entire source text. |
| Intention                                    | analysis of attention, information and appeal + successful / not successful? |

Work through these criteria in your text and divide them logically into linguistic analysis, content analysis and stylistic analysis.

### Conclusion

In the conclusion, you share your own opinion, but without using `Ich` (I). You mainly focus on evaluating the author's intention. Usually, you ask yourself the question: _How well did the author succeed in convincing you of_ her / his _opinion?_ Justify all your statements!

## Useful phrases

In a text analysis, it definitely helps to learn phrases by heart, since the same criteria are analysed in every text analysis. As the text is written in German, the phrases are given in German.

### Analysis of content, structure and argumentation

| Phrases (German)                                                                            |
| ------------------------------------------------------------------------------------------- |
| Der _Bericht / Kommentar_ ... thematisiert ...                                              |
| _Die Autorin / Der Autor_ setzt sich mit _der Frage / dem Problem_ ... auseinander, ob ...  |
| _Die Autorin / Der Autor_ erörtert die Frage nach ...                                       |
| _Die Autorin / Der Autor_ _kritisiert / zeigt_ sich befremdet darüber, dass ...             |
| Die zentrale These ist ...                                                                  |
| In diesem Zusammenhang geht _die Autorin / der Autor_ auf folgende Sachverhalte ein: ...    |
| Der Sachverhalt wird mithilfe von ... _erklärt / erläutert / illustriert_.                  |
| _Die Autorin / Der Autor_ _untermauert / veranschaulicht_ _ihre / seine_ Forderung nach ... |
| _Die Autorin / Der Autor_ erläutert _ihre / seine_ Position, indem ...                      |
| An folgendem Beispiel verdeutlicht _sie / er_, ...                                          |
| Diese Textstelle _belegt / veranschaulicht_, dass ...                                       |
| Die Thesen werden von _Expertinnen / Experten_ _gestützt / infrage gestellt_ ...            |

### Analysis of the linguistic design

| Phrases (German)                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------- |
| _Die Glosse / Der Kommentar / etc._ ist _sprachlich anspruchsvoll / leicht verständlich / betont einfach gehalten_. (Beispiel anführen!)    |
| Die Ausdrucksweise ist insgesamt _sachlich / emotional / ironisch_ ...                                                                      |
| _Die Argumentation wird / Die Gedanken werden_ in Form umfangreicher _Hypotaxen / Parataxen_ entwickelt. Das bewirkt ..                     |
| Der Bericht ist mit vielen _Fremdwörtern / Fachvokabeln_ gespickt (Beleg nicht vergessen!), was den Eindruck erweckt, ...                   |
| Häufig wird auf rhetorische Figuren wie ... zurückgegriffen, _was / dies_ ... _bewirkt / verstärkt / deutlich macht_, dass ...              |
| Auffällig ist die Verwendung von Begriffen aus dem Wortfeld ..., was ... unterstreicht.                                                     |
| _Die Autorin / Der Autor_ verwendet häufig (rhetorisches Mittel und Textbeleg einsetzen). Dies _wirkt ... / erweckt den Eindruck, dass ..._ |
