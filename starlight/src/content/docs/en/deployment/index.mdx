An application is only really finished when it can be reliably **deployed** and operated. This involves more than just the program code: servers have to be provisioned, and data has to be stored safely and backed up regularly. This section covers the infrastructure that modern applications run on.

## What to expect

- **Virtualisation:** Type 1 and type 2 hypervisors, paravirtualisation and container virtualisation with Docker.
- **Storage systems:** Differences between DAS, NAS and SAN as well as RAID.
- **Backup strategies:** Full, differential and incremental backups, the generation principle, the 3-2-1 rule and tape drives (LTO).
