An application is only really finished when it can be reliably **deployed** and operated. This takes more than program code: servers have to be installed and configured, users and permissions managed, data stored and backed up securely, systems monitored and protected from the outside. This section covers the infrastructure on which modern applications run, as it is built up in systems engineering from the second to the fifth year of technical college.
