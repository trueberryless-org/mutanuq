In most companies and schools, Windows Server is the backbone of IT: it manages user accounts, distributes settings to all PCs, resolves names, assigns IP addresses and provides file shares. These pages take you from installation to a complete domain. The examples use PowerShell throughout, because every step can then be traced, repeated and automated.

![Lab network with two domain controllers, a file server and a client](/images/deployment/lab_network_en.svg)

All examples refer to this lab network with the domain `corp.example.com`. The best way to follow along is to rebuild it with virtual machines, for example with Hyper-V (see [virtualisation](/en/deployment/virtualisation/)).
