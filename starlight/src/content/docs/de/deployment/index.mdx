Eine Anwendung ist erst dann wirklich fertig, wenn sie zuverlässig **bereitgestellt** (_deployed_) und betrieben werden kann. Dazu gehört mehr als nur der Programmcode: Server müssen bereitgestellt, Daten sicher gespeichert und regelmäßig gesichert werden. Dieser Bereich behandelt die Infrastruktur, auf der moderne Anwendungen laufen.
