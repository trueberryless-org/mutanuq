Eine Anwendung ist erst dann wirklich fertig, wenn sie zuverlässig **bereitgestellt** und betrieben werden kann. Dazu gehört mehr als nur der Programmcode: Server müssen installiert und konfiguriert, Benutzer und Rechte verwaltet, Daten sicher gespeichert und gesichert, Systeme überwacht und nach außen abgesichert werden. Dieser Bereich behandelt die Infrastruktur, auf der moderne Anwendungen laufen, so wie sie in Systemtechnik vom zweiten bis zum fünften Jahrgang aufgebaut wird.
