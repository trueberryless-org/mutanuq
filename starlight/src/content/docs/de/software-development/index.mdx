Die Softwareentwicklung ist das Kernfach der Informatik an der HTL. In diesem Bereich lernen Sie, wie man Programme nicht nur zum Laufen bringt, sondern so aufbaut, dass sie **verständlich**, **erweiterbar** und **wartbar** bleiben – auch dann, wenn viele Personen über mehrere Jahre daran arbeiten.

Die Beispiele auf diesen Seiten sind in **C#** geschrieben, lassen sich aber mit wenigen Anpassungen auf Java oder andere objektorientierte Sprachen übertragen.
