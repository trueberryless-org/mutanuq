Das verwendete Liquid Crystal Display (LCD) ist ein sogenanntes Zeichendisplay mit 16 Zeichen pro Zeile und 2 Zeilen insgesamt. Solche Displays verwenden fast immer den Controller **HD44780** (oder einen kompatiblen Nachbau). Dieser enthält einen fest eingebauten Zeichensatz mit den ASCII-Zeichen sowie je nach Variante japanischen Katakana-Zeichen oder europäischen Sonderzeichen. Zusätzlich kann man bis zu acht eigene Zeichen (5 × 8 Pixel) definieren, etwa für Umlaute oder kleine Symbole.

Für die Verwendung des Displays empfiehlt sich die Bibliothek von Peter Fleury mit den Dateien <a href="/embedded_programming/lcd/lcd.c" download>lcd.c</a> und <a href="/embedded_programming/lcd/lcd.h" download>lcd.h</a>. In der `lcd.h` wird eingestellt, an welchen Pins das Display angeschlossen ist.

## Aufbau

Das Display wird meistens im **4-Bit-Modus** betrieben. Dabei werden nur die Datenleitungen D4 bis D7 sowie die Steuerleitungen RS (Register Select) und E (Enable) mit dem Mikrocontroller verbunden. Die Leitung RW kann fest mit GND verbunden werden, wenn man nur auf das Display schreibt. Über ein Potentiometer am Pin V0 wird der Kontrast eingestellt.

## Code

Das LCD hat einige Möglichkeiten, Zeichen zu verändern, zu löschen und hinzuzufügen. Vor der ersten Verwendung muss es mit `lcd_init(LCD_DISP_ON);` initialisiert werden.

### Schreibe Zeichen

Man kann einzelne Zeichen mit `lcd_putc('s')` aufs Display schreiben oder einen ganzen String:

```c
lcd_puts("trueberryless");
```

### Cursor positionieren

Mit `lcd_gotoxy(x, y)` setzt man den Cursor an eine bestimmte Stelle. `x` ist die Spalte (0 bis 15) und `y` die Zeile (0 oder 1):

```c
lcd_gotoxy(0, 1);   // Anfang der zweiten Zeile
lcd_puts("Zeile 2");
```

### Display leeren

Um alle Zeichen auf dem Display wieder zu löschen:

```c
lcd_clrscr();
```

### Bewege Zeichen

Wenn man alle Zeichen um eins nach links bewegen möchte, kann man das so machen:

```c
lcd_command(LCD_MOVE_DISP_LEFT);
```

Dies ist äußerst hilfreich, wenn ein Text übers Display laufen soll.

### Beispielprojekt

Das folgende Programm liest alle zwei Sekunden Temperatur und Luftfeuchtigkeit von einem DHT11-Sensor (mit einer passenden Bibliothek `dht.h`) und zeigt die Werte am Display an:

```c
#define F_CPU 16000000

#include <avr/io.h>
#include <avr/interrupt.h>
#include <stdio.h>

#define __DELAY_BACKWARD_COMPATIBLE__
#include <util/delay.h>

#include "lcd.h"
#include "dht.h"

int main(void)
{
    char buffer[17]; // 16 Zeichen + abschließendes '\0'

    int8_t temperature = 0;
    int8_t humidity = 0;

    lcd_init(LCD_DISP_ON);

    while(1) {
        if (dht_gettemperaturehumidity(&temperature, &humidity) != -1) {
            snprintf(buffer, sizeof(buffer), "T: %d C, H: %d%%", temperature, humidity);
            lcd_puts(buffer);
        }
        else {
            lcd_puts("Error");
        }
        _delay_ms(2000);
        lcd_clrscr();
    }
}
```

`snprintf` schreibt dabei höchstens so viele Zeichen in den Puffer, wie dieser groß ist, und verhindert so einen Pufferüberlauf. Das Prozentzeichen muss im Formatstring als `%%` geschrieben werden.
