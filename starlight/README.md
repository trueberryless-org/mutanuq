# mutanuq

The Starlight site of [Mutanuq](https://mutanuq.netlify.app), the open knowledge platform for students of the HTL Krems.

## Development

Run all commands from the root of the repository:

| Command        | Action                                              |
| :------------- | :-------------------------------------------------- |
| `pnpm install` | Install the dependencies                            |
| `pnpm dev`     | Start the development server on `localhost:4444`    |
| `pnpm build`   | Build the production site to `starlight/dist/`      |
| `pnpm check`   | Type-check the project                              |

Content lives in [`src/content/docs/`](https://github.com/trueberryless-org/mutanuq/tree/main/starlight/src/content/docs), with one directory per language (`de` and `en`).
